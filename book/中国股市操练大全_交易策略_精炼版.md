## 第8章 技术指标法则

## 8.2 技术指标的常用法则

### 8.2.1 指标背离
- **定义**：指标波动方向与价格趋势不一致（价格得不到指标支持），分顶背离与底背离：
  - **顶背离**（上涨后期）：价格高点高于前次高点，但指标高点低于前次高点 → 见顶卖出信号。
  - **底背离**（大幅下跌后）：价格低点低于前次低点，但指标低点高于前次低点 → 见底买进信号。
- 能形成明显背离的指标：MACD、WR、RSI、KDJ，其中 **RSI、KDJ 背离成功率较高**。
- 高位：价格出现**一次顶背离即确认见顶**；低位：常需**多次底背离**才确认见底。
- 暴涨/暴跌行情中 KDJ 高位或低位钝化后仍继续，此时一旦出现背离**有效性很高**；KDJ+RSI 合用效果好。
- 假背离识别：
  - 某一时间周期背离、其他周期不背离（如日线背离但周/月线不背离）为假。
  - 指标未进入高位区即背离：指标**高于80或低于20出现背离才有效**；20~80 之间出现的不予理会。
  - 单一指标背离参考意义不大，**多指标同时背离可靠性高**（灵敏度 KDJ>RSI>MACD）。

### 8.2.2 技术指标的交叉、低位和高位
- **黄金交叉**：上升中的短周期指标线由下向上穿过上升中的长周期指标线 → 看涨。
- **死亡交叉**：下降中的短周期指标线由上向下穿过下降中的长周期指标线 → 看跌。
- **与0轴交叉**：指标线上穿0轴 → 空方转多方，看多；下穿0轴 → 多方转空方，看空。
- 低位=超卖区，高位=超买区（以 KDJ 为例）：
  - KDJ 由低升到高**超过80** → 超买，价格随时回落，警惕。
  - KDJ 由高降到低**低于20** → 超卖，价格随时反弹，关注。
- **高位钝化**：指标在高位、价格大幅攀升且指标升幅越变越小（上升抛物线状），只出现在强势特征明显的市场；**低位钝化**只出现在极度弱势市场。

### 8.2.3 技术指标的徘徊、转折和盲点
- **徘徊**：指标在进退不明状态，无法明确判断方向。
- **转折**：指标在高低位调头，表明超买/超卖状态将平衡；有时预示一趋势结束、另一趋势开始。
- **盲点**：大部分时间指标发不出买卖信号（尤其价格盘整震荡时多失灵）。每个指标都有失效的盲点，需总结盲点并找替代指标。
- 结合 K线、形态、趋势等共同分析，可提高指标准确率。

> **注意**：指标图形可能被主力通过操纵价格制造假信号，要结合大势与主力特征识别，避免“一买就套，一卖就涨”。

## 8.3 MACD指标

### 8.3.1 MACD指标概述
- 图形由 **DIFF线、DEA线、柱状线** 组成。
- **DIFF** = 快速均线(12日) − 慢速均线(26日)；值为正=正差离值，负=负差离值。持续上涨正差离值变大，下跌负差离值绝对值变大。
- **DEA** = DIFF 的算术平均值（辅助线）。
- **柱状线** = DIFF − DEA；DIFF 在 DEA 上方为正、0轴上方红柱（做多）；下方为负、0轴下方绿柱（做空）。
- DIFF/DEA 在**0轴下方=空头市场；0轴上方=多头市场**。
- 0轴上方红柱增多拉长→多方强、行情继续；红柱缩短→多方衰减、随时下跌。0轴下方绿柱增多拉长→空方强、继续；绿柱缩短→空方衰减、止跌见底回升。

### 8.3.2 读懂重要的MACD指标图
- **MACD上穿0轴**（负转正）→ 走势转强势，看多做多。**月MACD上穿0轴**表明将有一大段升幅，可及时买进。
- **MACD下穿0轴**（正转负）→ 走势转弱势，看空做空，反弹时逢高卖出。**月MACD下穿0轴**表明将有一大段跌幅，及时清仓离场。
- **MACD调头向上**（DIFF下转上且上穿DEA=黄金交叉）：
  - 0轴上方调头向上 → 震荡回调结束，可买进。
  - 0轴下方调头向上 → 反弹开始，可买进抢反弹（博短差）。
- **MACD调头向下**（DIFF上转下且下穿DEA=死亡交叉）：
  - 0轴上方调头向下 → 震荡回调开始，观望；**月MACD调头向下**尤其注意。
  - 0轴下方调头向下 → 反弹结束，果断抛空。
- **顶背离**（价格逐波上涨、MACD逐波下跌）：升势完成，短期很可能见顶；价格大幅拉升后再现死亡交叉，见顶回落可能性更大，趋势向下即果断清仓。
- **底背离**（价格逐波下跌、MACD逐波走高）：跌势完成，短期很可能见底；价格大幅下跌后现黄金交叉，见底回升可能性更大，可做准备进场或少量资金先进场。
- 高位**一次顶背离即可确认见顶**；低位**常需多次底背离**才确认见底。
- 假背离：某一周期背离、其他周期不背离（如日线背离而周/月线不背离）= 假背离。

### 8.3.3 MACD指标应用规则
- 下跌后出现底背离 + MACD 不降反升 → 止跌回升信号，不再做空。
- 0轴下方出现黄金交叉（多次粘合后金叉）→ 只能做反弹（仍为空方市场）。
- 反弹上升中 MACD 上穿0轴 → 空方转多方，可逢低大胆买进并持有。
- 0轴上方回调后**0轴处黄金交叉** → 强烈买进信号。
- 上涨途中 0轴上方多次死叉/金叉 = 短期调整信号，可持股待涨。
- 大幅上涨后加速上涨 + 红柱迅速放大 + 顶背离 + 死亡交叉 → 见顶信号，果断清仓；清仓后短期不再介入该股（防接主力出货盘）。
- 高位 MACD 上行到 0轴之上但**粘合**（不快速上升）= 主力拉高出货，看空。
- **使用限制**：MACD 是中线趋势类指标，需多指标对照验证；**盘整或行情波动过小时不适用**。

## 8.4 KDJ指标

### 8.4.1 KDJ指标概述
- 由 K、D、J 三线组成，反应速度 **J 最快、K 次、D 最慢**；取值范围 0~100（J 可超 100 或低于 0）。
- 使用要领：
  - **D 值向上接近或超过 80** → 超买区，股市可能下跌。
  - **D 值向下接近或跌破 20** → 超卖区，反弹增强。
  - **J 值 >100** 超买；**J 值 <10** 超卖。
  - **K 从下方上穿 D（K>D）** → 上涨，行情上涨，可适当买进。
  - **K 从上方下穿 D（K<D）** → 转跌，可适当卖出。
  - K、D 反复在 50 附近震荡 → 行情整理，结合 J 值判断。
- **价线背离**：层层拔高而 K、D 层层降低（或相反）→ 行情转向，及时变换投资行为。
- **不适用**：股价变动过快时。

### 8.4.2 KDJ指标应用规则
- 震荡市用灵敏的 **J 线**判断超买卖：J 接近 100=超买（短期卖点）；J 接近 0=超卖（短期买点）。
- **周线 KDJ** 形成买入信号 → 预示一轮中级上升行情，可配合指标买入做中线。
- **月线 KDJ** 蕴涵长期战略性方向，对月线以下各指标起指导作用。
- **买点**：月线 KDJ **J<20** 且周线 KDJ **J<10** → 一轮暴涨行情正在孕育，敢于进场买入。

## 8.5 RSI指标

### 8.5.1 RSI指标概述
- 参数可 6、12、24 天；理性选择参考 **6天与12天**。
- 使用要领：
  - 短周期 RSI1 定为 **5或6天**，长周期 RSI2、RSI3 定为 **12、24天**。
  - **RSI 升到 70 以上** → 追涨要小心，最好卖出。
  - **RSI 降到 20 以下** → 适时进货。
  - **快速 RSI 上穿慢速 RSI** → 买入；反之卖出。
  - 走势背离：股价升、RSI弱 → 买力不强，卖出；股价跌、RSI强 → 买力强，可持仓。
- **缺点**：信号过于强烈、示警过早，慢牛爬升行情中易造成踏空。

### 8.5.2 RSI指标应用规则
- **RSI 最大作用是判断主力出货**（庄家卖出）。主力最后出货时常现**顶背离**：股价创新高、RSI 不创新高反下降 → 上升趋势终结、向下反转，及时卖出。
- **底背离**：股价创新低、RSI 不创新低反上升 → 下降趋势结束、向上反转。
- 周期有效性：
  - **日线**的顶/底背离表示短线趋势，实用价值不大、难把握。
  - **周线**背离表示中期趋势重大转折。
  - **月线**背离表示长期趋势重大转折，**准确率相当高**。

## 8.6 BOLL（布林通道）指标

### 8.6.1 BOLL指标概述
- 由上、中、下三轨构成；价格多在带状区间内运行，**带越宽变动越大**。
- **价格在中轨以上** → 趋势看强；**中轨以下** → 趋势看淡。上轨=极强，下轨=极弱。
- 使用要领：
  - 股价**中轨上方** → 较安全，短线持有观望。
  - 股价**中轨下方** → 较危险，短线应趁反弹到中轨时离场。
  - 股价**突破上轨后回探中轨不跌破中轨** → 看涨，持股或加仓。
  - 股价**跌破下轨后反弹不站回中轨以上** → 看跌，果断卖出。
  - 通道**急剧变窄收拢** → 方向重大转折，需配合其他指标判断。
- 特别适用于波段操作。

### 8.6.2 BOLL指标应用规则
- 沿上轨运行、回调到**中轨不破**止跌 → 加仓点（可反复加仓）。
- 从上轨突然下调到中轨，且 K线出现**大阴线 + 成交量放大** → 可加仓但需警惕（可能快见顶）。
- 从上轨下跌到中轨**未止跌继续向下** → 减仓；沿下轨运行=后市看跌，反弹逃命 → 减仓或清仓出局。

## 8.7 BIAS（乖离率）指标

### 8.7.1 BIAS指标概述
- **公式**：
  - 指数乖离率 = (当日收盘指数 − N日平均指数) / N日平均指数 × 100%
  - 个股乖离率 = (当日收盘价 − N日平均股价) / N日平均股价 × 100%
- N 一般为 **5、6、10、12、24、30、72**。短线用 **6日**乖离率有效；中线放大为 **10日或12日**。
- 乖离率超常态范围 → 股价向均线靠拢。
- 应用规则：
  - **乖离由负转正且均线上移** → 跟进做多。
  - 乖离由正转负且均线上移 → 持股待售；**均线下移 → 卖出**。
  - 乖离**接近历史最大值** → 多方发威近极限，行情随时向下，**减仓**（勿追高）。
  - 乖离**接近历史最小值** → 空方发威近极限，行情随时掉头，**逢低吸纳**（勿割肉）。

### 8.7.2 BIAS指标应用规则
- 乖离接近**历史最大值**时 = 股价阶段性高点/最高点 → **卖出正确**。
- 乖离接近**历史最小值**时 = 股价阶段性低点/最低点 → **可适量买入**；结合均线：均线上走→持股待涨，均线下走→做短线搏反弹。

> **提醒**：BIAS 最长处是预警股价暴涨暴跌引发的行情逆转，其他作用不强。

## 8.8 技术指标运用注意事项

### 8.8.1 技术指标结构性问题
- 各指标取材于开盘/收盘/成交量等要素，取向片面且相似；只能滞后揭示价格状况；只是统计结果不能揭示行情本身。
- 指标有**适用盲区**：MACD 在盘整时无效、KDJ 在趋势明显时无效（很多人不知）。
- 多指标验证时，要么信号给得晚，要么不知信哪个。

### 8.8.2 技术指标数据源问题
- 技术指标只依赖 开/高/低/收/量 等数据，**操纵这些数据即可操纵指标**。
- 例：**RSI 只涉及收盘价**，连续 5 天操纵收盘价持续跌涨，RSI 即等于 0 或 100；流通盘小的股票易操纵收盘价。
- 多指标相互验证时因**数据来源几乎相同**，用同源统计信号求一致信号，有效性大打折扣。
- 技术指标只是单一统计工具，需结合大盘形势、个股股质、主力操盘手法综合判断。

### 8.8.3 主力操纵技术指标的方法
- **方法1**：指标将见顶前尽量拉高股价——向上突破后在市场抛盘尚未挂出的瞬间（或对倒）拉出**无量的最高价**，让指标从最高价算起从而快速回落。
- **方法2**：第一天回落时加大出货力度，打出较低低点并形成**宽幅震荡**——相对昨收跌幅大，低点抛盘少、反弹接盘多，可出掉不少筹码。
- **方法3**：隔天奋力上推——利用前日跌幅吸引买单进场，来回折腾后市场平静，若主力不再对倒则成交量迅速萎缩、股价进入调整，技术指标也回调到位。
- **结论**：强势股指标调整一般到中位区即可（调整约一周），主力可借此让指标在股价跌幅不大时**快速调整到位**。

## 第12章 投资法则与策略

## 12.1 计划你的交易，交易你的计划
- 交易计划应含：大盘与个股行情分析、进场计划、随机应对策略、出局策略、纪律执行保障。

### 12.1.1 大盘和个股行情分析
- 先判大盘行情类型（趋势/盘整），明确长/中/短期趋势及所处阶段。
- **最低限制**：只在中长期趋势的发展阶段操作，**禁止在趋势末端冲动操作**。
- 个股分析五要素：
  - (1) 基本面：政策导向、供求关系、市场规律；
  - (2) 短期/中期/长期技术图形在价格趋势上是否一致；
  - (3) 技术位置是否处短线趋势起始点、附近有无支撑/阻力位、可否就近设置止损；
  - (4) 价格波动空间（潜在风险报酬比）；
  - (5) 是否为最佳介入时机。

### 12.1.2 进场计划
- 进场信号必须**清晰、唯一、不模棱两可**，基于牢固逻辑。计划五要素：
  - (1) 大体进场价位区间；
  - (2) 建仓资金量；
  - (3) 盘中紧贴止损位设置；
  - (4) 走势符合预期是否加仓；
  - (5) 保证符合条件时按计划进场。

### 12.1.3 随机应对策略
- 事先预测未来一天/几天几种可能走势，分别准备对策：
  - (1) 明天可能走势有几种；
  - (2) 针对每种走势采取的策略；
  - (3) 与预期相反走势下止损位的调整；
  - (4) 符合预期时是否加仓；
  - (5) 止赢位的大体设置。

### 12.1.4 出局的策略
- 出局实质 = 持仓理由消失。明确：
  - (1) 走势未按预期时的止损出局条件；
  - (2) 顺应趋势时赢利目标设在何处，到位置减仓还是全部退出；
  - (3) 短暂盘整/回抽时跟踪止损位设在何处；
  - (4) 阶段盘整震荡时是否减仓或清仓。

### 12.1.5 纪律执行保障
- (1) 非计划中的交易坚决不做，无好机会只等待忍耐；
  - (2) 出现计划中的交易不犹豫，坚决按计划进场；
  - (3) 交易中严格按计划控制；
  - (4) 出现计划中的出局/减仓条件，不折不扣执行。

## 12.2 顺势而为
- 市场永远是对的，只依据正在发生的情况处理眼前行情，不盲目预测反转。

### 12.2.1 顺势而为，高抛低吸
- **适用**：大盘刚触底、处反弹阶段的震荡反弹行情，个股多为超跌反弹 → 用**高抛低吸**（避免来回坐电梯）。

### 12.2.2 顺势而为，持股待涨
- **适用**：大盘已回暖、个股形成上升趋势 → **持股待涨**，不做高抛低吸。
- 上升趋势明显的股票，看是否沿重要均线（**5/30/60日均线**）向上攀升，**只要均线未破就耐心持股**，获得最大收益。
- **提醒**：单边上涨行情只能持股待涨，不能高抛低吸，更不能反向操作；不能主观认为涨太多就会跌。

## 12.3 抓住赢多输少的机会
- 行情反复震荡盘整、走势不明朗（看不懂）时 → **最佳策略是不操作**，耐心等待。
- 真正的行情（趋势）来了，要果断跟进，不能犹豫。

## 12.4 买进要谨慎而卖出要果断
- 核心法则：**买进谨慎，卖出果断**（下跌容易上涨难，底部形成时间长、顶部形成时间短）。散户常见反向错误：买进果断、卖出犹豫 → 输钱主因。

### 12.4.2 买进要谨慎
- 大幅下跌后低位出现大阳线或买入信号 → **不能马上看多**，信号可能是主力诱多；上涨趋势未形成前盲目做多会吃大亏。
- 除非牛市普涨阶段，买进要慎之又慎；做多需看政策、资金流向，并多指标多角度验证。
- K线信号不能只看一两天，要结合**周K线、月K线**整体把握。

### 12.4.3 卖出要果断
- 大涨后**高位出现大阴线** → 高度警惕，表明上涨势头已尽，大幅下跌早晚会来（即使当下不马上跌），应果断卖出。
- 不要因已被套 5%~10% 不肯认输、等反弹出局（往往越等套越深）。

## 12.5 学会接受失败

### 12.5.1 失败是股市操作的一部分
- 股市是零和（甚至负和，含税与佣金）游戏，亏损是操作结果的一部分，坦然面对。
- **市场走势不利时敢于承认错误、及时止损**。即使成功概率只有 50% 甚至更低，靠小止损也能获利 ——《利用小的止损赚大钱，止损是获利的成本》。

### 12.5.2 败中求胜
- 成功的投资者从失败开始，关键是坚定信心并总结经验。
- **摆脱困境最基本办法：停止操作**。行情对自己不利时要尽量减仓，保全自己避免深套。

## 12.6 金字塔形买卖法
- **买进（建仓）**：先投少量资金，股价越下跌投得越多，呈金字塔形（上小下大）。例：6万资金，4.50买2000股→下跌到4.20买3000股→4.10买4000股→4.00买5000股（14000股，均价4.14）。
  - 特点：越跌越买 → 摊低持仓成本、增加持股数量、根基扎实。
- **卖出**：以**倒金字塔形**操作——股价上涨时一路获利了结，卖出的数量随股价上升而增加（越卖越多）。
- 适用范围：股市大幅下跌后陷入低迷时效果显著，胜多负少。

## 12.7 有暴利便收手
- 突然遭遇大行情、手中有**大额浮动利润**时 → 原则是**立即清仓**，把浮动利润落实为已收帐。
- 一个月内浮动利润达 **50%以上** 就要警惕收手：他人会获利回吐、后来者少追高，盘整不可避免，利润会缩水甚至归零。

## 12.8 投资不能太分散
- 人的精力时间有限，不能同时操作太多只股票；最好只做**自己熟悉的几支股票**。
- 锁定熟悉股票，根据业绩、流通盘、题材、波动高低点确定**具体买卖价位**，接近目标价位才进出。
- 做中长线的两个条件：
  - **要专注**：只关心几个熟悉股票，须是在近年来有明显高低点、一定范围内运行的股票（非单边跌/涨）。
  - **要忍耐等到时机成熟**：如波动区间 6~15 元，则在**前低 6+6×5% 下方吸纳，前高 16−16×5% 上方卖出**（宁可资金空着也不追，宁可少赚也坚决出局）。
- 常犯三种错误：该抛不抛（看高一线、来回坐电梯）；急于补仓（跌 20%/30% 就补，忘了几跌到前低附近再买）；该买不买（空仓资金去买别的股被套）。
- 风险回报哲学：
  - 要敢赚不敢亏（有胆赚没胆亏则必败）。十次五赚五亏，需**小亏大赚**（逆市死撑、顺市早跑就反了）。
  - 成功交易讲"稳准狠"；抓住机会别放手，赚足大胜盖过小亏。
  - 担心行情反复要有根据（突发消息逆转、升势近阻力、跌势近支撑、RSI超买卖、市场一边倒），无转向信号就抓住不放。
  - 波浪底部买入后涨势刚起步，不必急着平仓，让利润奔跑。
- **制胜法则：亏的时候要设限，赚的时候要赚足。**

## 第13章 避免惨重损失

## 13.1 股民遭受惨重损失的原因
- 主要因：大小非大量减持、超级利好未兑现、借钱炒股、上市公司违规被处罚、购买高价股、股市整体下跌。

### 13.1.1 大小非大量减持
- 大非=占总股本5%以上的限售流通股；小非=5%以内。股改后大小非低成本，解禁套现冲动大。
- **判断方向**：
  - 股市总体向好 + 基本面优秀 → 解禁可带来投资机会（解禁前期心理压力致调整，解禁后优质基本面吸引资金推高）。
  - 平衡市/弱势 + 基本面不佳 → 解禁负面影响大，可能深幅调整（例：海通证券解禁当天跌停、连续跌停挡不住抛单）。
- 需关注限售股解禁时间与数量，解禁期警惕跌停/抛压。

### 13.1.2 超级利好未能兑现
- 有政策/行业/业绩预增等超级利好但**内外部因素未实质向好** → 利好不能实现，信心受打击、资金出逃、股价快速下跌。
- 警惕"利好落空"风险：复牌后往往连续跌停（例：重组预期落空连续两个跌停）。

### 13.1.3 借钱炒股
- 借钱炒股放大亏损：3万自有跌30%亏9000；借7万共10万跌30%亏3万=本钱亏完。
- **规则**：只用余钱炒股，不借钱炒股、量力而行。

### 13.1.4 上市公司违规被处罚
- 上市公司因违规受处罚 → 股价大幅下跌、连续跌停。规避有违规/信息披露不及时风险的公司。

### 13.1.5 购买高价股
- 高位买入被套且不及时止损 → 深套。高位买入追涨风险极大，务必设置止损。

### 13.1.6 股市整体下跌
- 大盘创历史新高后往往发生系统性大跌（多数股票跌幅达70%左右）；管理层宏观收紧也是触发因素。
- 注意历史规律：**股指创历史新高 + 涨幅巨大 + 政策调控 → 警惕整体下跌**。

## 13.2 股民如何避免被深套
- 操作先想失败怎么办；对重要下跌技术图形要熟记并果断应对。

### 13.2.1 利用死亡谷避免深套
- **死亡谷** = 均线系统出现的死叉组合，是相当危险的下跌信号，股价大幅上涨后出现死亡谷更危险，**越早出局越好**。
- 级别威力从小到大：日线 < 周线 < 月线。
  - **月K线死亡谷**威力最大 → 常熊一两年甚至更久，长期投资者一两年内不碰该类股。
  - **周K线死亡谷** → 常熊半年以上，短时间内不能碰；只有股价跌出底部、震荡向上、所有均线完全走高后才重新关注。
  - **日K线死亡谷** → 短期转弱，及时减仓。
- 若**周K线、月K线**见死亡谷，更应果断清仓。

### 13.2.2 利用向下跳空缺口避免深套
- 第一个**向下跳空缺口**的出现 = 一波跌势展开的标志；若同时大盘处于跌势，深幅下跌可能性更大，应**果断离场观望**。
- 缺口三类：向下突破缺口、向下持续缺口（都重要看空做空信号）、**第三向下竭尽缺口后不能再盲目看空做空**。
- 下跌漫长时可能出现第4、5个甚至更多向下缺口；见第三个向下缺口后认真观察，**股价慢慢走出底部后才动手**。
- 上升末端"见顶 + 放量 + 向下缺口"组合 → 逢高果断斩仓。

### 13.2.3 利用断头铡刀避免深套
- **断头铡刀** = 一根大阴线将多条均线（如5周/10周/30周）拦腰截断。股价/指数大幅上涨后出现相当危险，果断离场。
- 级别含义：
  - **日K线**断头铡刀 → 短期趋势彻底走坏，短线逢高减仓。
  - **周K线**断头铡刀 → 中长期趋势彻底走坏，不可轻视。
  - **月K线**断头铡刀 → 长期趋势彻底走坏，停止做多、坚决卖出、止损离场。
- 主力可能只在日K线/分钟K线上做反技术操作，周线/月线很少做。

## 13.3 防范其他投资者的各种陷阱

### 13.3.1 虚假交易
- 主力利用多个隐蔽账户**对倒**制造虚假需求/需求打压，拉高或压低股价后出货/吸筹。放量异常拉升可能为对倒陷阱。

### 13.3.2 制造假消息
- 主力捏造消息哄抬或打压股价从中渔利（例：A股H股互换假消息致大盘大跌后被否认）。对未经官方证实的消息保持警惕。

### 13.3.3 骗线陷阱
- 操纵者用 K线制造**虚假买卖信号**：如拉大阳线出货（散户视大阳线为买点）、打压收大阴线吸筹。
- 应对：不迷信单一K线信号，结合放量/位置/其他指标识别骗线。

### 13.3.4 操纵股市
- 个别庄家用多个账户操纵个股（异常暴涨即监管目标）。异常脱离基本面的暴涨勿盲目跟风。

### 13.3.5 荐股陷阱
- **专家荐股**：可能与庄家/上市公司勾结，上涨时"吹股手"、出货时"强力推荐"，诱导散户高位接货。**券商荐股**：熊市也可能不断推荐买入，只能当参考勿盲目跟随。**短信/博客荐股**：动机不纯（卖会员收钱、庄家"托儿"），谨慎对待、独立思考。

### 13.3.6 内幕交易
- 内幕人员先于公众获知信息。对公司异常连续涨停+利好公告需警惕内幕风险，勿追高。

### 13.3.7 老鼠仓
- 庄家/基金经理先以个人资金低位建仓，再用公有资金拉高后个人先卖出获利（散户最后接盘受损）。勿盲目跟风基金重仓拉升股上涨初段。

## 第14章 选股策略

## 14.1 选股的重要性及策略
- 选股是炒股赚钱第一步也是最难一步；每次上涨行情中，涨升个股约占一半，跑赢大盘的个体更少。
- 四种基本选股方法：
  1. **价值发现**：用市盈率、市净率等指标发现价值被低估个股（理论基础为价格向价值回归；需较强专业知识）。
  2. **选择高成长股**：关注未来利润高增长（高科技股），淡化市盈率等传统价值标准。
  3. **技术分析选股**：基于 ①市场行为涵盖一切信息 ②价格沿趋势变动 ③历史会重演。不关注基本面，用图表/技术指标寻找**超跌个股**捕捉机会。
  4. **指数投资组合**：不选股，参照指数构成做组合或买指数基金，取得与大盘同步收益。

## 14.2 利用国家经济政策来选股
- 基本面分析首先学会**按政策选股**；理解政策深的才能选出好股。
- 学习渠道：关注《上海证券报》《中国证券报》头版（高层重要讲话），或听经济专题讲座；网络可第一时间获取政策。
- 深刻理解方法：多问自己（什么是该政策概念、投资范围、短线还是中长线机会、哪些行业/板块最受益、主力将如何利用等），带问题查资料。
- **实例要点（万科A）**：行情底部区域 + 政策受益行业龙头 + 均线**粘合向上发散** + MACD黄金交叉后**上穿0轴** + **放量突破前期高点** → 重仓买入，一路持有；见顶信号（高位倒T字、重心下移、5/10日均线粘合向下、MACD死叉）→ 卖出；MACD续滑 + 三死叉（死亡谷）+ 高位放量盘整（主力出货）→ 清仓。

## 14.3 利用价值投资来选股
- 选绩优股：利润、净资产收益率、每股收益均高。

### 14.3.1 为什么投资绩优股也会亏损
  1. **绩优股长线有价值、短线不一定**：投机力量大时，绩优股会被冷落（贵州茅台也曾在 39.69→25.88 下跌）。
  2. **有些非真绩优**：利润来自政府补贴/资产转让而非主营 → 一旦"绩优外衣"被剥去即价值回归（新大陆 40%利润靠政府补贴）。
  3. **受外部环境影响大**：景气度高时业绩上升、景气变差业绩下滑（厦新电子 1998 每股1.02元→2000年-0.49元，40元→10元）。

### 14.3.2 主营业务指标
- 关注利润是否主要来自**主营业务收入**（靠自己赚的，非他人恩赐）。
- 高速发展公司全力投入主营、非主营不受重视；多元化经营公司通常主营业务不突出、盈利不稳定甚至一次性业绩。
- 绩优股=主业兴旺；重点关注 F10 财务分析中的主营业务收入判断长期价值。

## 14.4 利用市盈率来选股

### 14.4.1 什么是市盈率
- 市盈率 = 股价/每股税后利润；静态参考指标。15倍表示需15年收回成本。

### 14.4.2 辩证看待市盈率
- 世界通行观点：**20倍以下才值得投资；15倍以下为"国际标准安全线"**（但中国股市常相反）。
- 市盈率是静态短期指标，只看过去一年；未来利润可变（政策、经济周期、经营波动），**不能完全按市盈率买**。
- **高成长股市盈率高反而更有价值**：例 A股14元增8%/B股20元增20%/C股30元增50%，现市盈率28/40/60，5年后仅C上涨。

### 14.4.3 静态市盈率和动态市盈率
- **动态市盈率** = 预测的新一年业绩 ÷ 股价。实际选低市盈率应选**动态市盈率低**，静态只作参考。
- 周期性行业（钢铁）：静态高≠不能买（需求旺→动态走低，2003钢铁被重仓上涨）；静态极低≠值得买（基本面转差→动态走高，2005钢铁6倍市盈率被抛、股价腰斩）。
- **光看静态市盈率会造成重大失误**。

### 14.4.4 市盈率的应用技巧
- 低市盈率应为**动态**而非静态。
- 业绩稳定股：静态与动态高度一致。
- **周期性行业**：关注行业景气度比静态市盈率更重要。
- **高科技股**：静态与动态常不一致，关注自主创新动力、核心技术是否掌握。

## 14.5 利用公开信息来选股

### 14.5.1 公开信息与小道消息的区别
- 公开信息 = 年报 + 上市公司重要公告（审计过、相对可靠）；小道消息是主力刻意传播的欺骗手段（低位无声、上行渐广、到顶铺天盖地）。
- **只用公开信息，不用小道消息**。

### 14.5.2 从公开信息中选择合适投资机会
- 从年报/公告中发现机会：关注主业业绩增长、前十大流通股东增减仓、股东户数变化、机构动向、产品涨价/垄断地位形成等（例华茂股份业绩翻倍+筹码集中→跳高突破买进涨80%；云南白药垄断+产品涨价公告→7元涨到17元）。

### 14.5.3 利用公开信息选股的原则
1. 再可靠的消息也要用自己熟悉的方法重新审视。
2. 有实质内容+把握大的消息可重仓；否则按技术分析操作。
3. 符合自己操作原则的消息可加大力度，否则减少或不参与。
4. **消息要与盘面对比**：好消息一出不升反降=利空，暂时退出；坏消息一出不跌反升=利好，继续持仓。
5. 消息常被主力用作操纵工具，去伪存真、不盲目追涨杀跌。
6. 消息公布越迟影响越小；同类消息出现次数越多影响越弱。

## 14.6 利用市场热点来选股

### 14.6.1 什么是市场热点
- 热点酝酿时间越长，能持续的时间就越长（酝酿是主力资金介入）。
- 热点三阶段：①单一热点发动（持续较长）→②扩散到多极热点（较短）→③转移与消退（更短）。
- 能炒的板块轮炒一遍后大盘进入休整期，等待下一单极热点。
- **热点不宜反复相信**：相信一次、两次对，三次以上即错（会吃大亏）。
- 应选**刚开始的单一热点**持股，持续长（几周~几月），热点刚出现时吃进一般有盈利。

### 14.6.2 利用市场热点来选股的技巧
1. **分清主流热点与一般热点**：
   - **主流热点**（大级别反转多头行情、大板块、号召力强）→ 行情为反转/大级别，**敢重仓做多、一路捂股**。
   - **一般热点**（小反弹/箱体行情）→ 行情可能是反弹，用**短多长空**策略（接近上一轮高点/密集区减仓）。
2. **买龙头（领头羊）**：热点板块中涨幅最好的非领头羊莫属；领头羊涨幅一般在**100%~200%**，主力不计成本塑造。行情初期出现热点板块，快速找出领头羊跟进、捂到板块转换。
   - **识别领头羊**：找出一段时期内**成交量、涨幅最大的股票**。
3. **把握热点转移与消退时机**：热点一旦形成不会马上结束（除非突发利空），升温到一定高度才退潮。最佳做法是在热点**开始转移时顺利退出**（退早了错过行情，退晚了变套牢）。
4. **参与要早**：启动初期**放量上涨**个股果断建仓；已涨一段时间后失去参与机会。一旦主力撤退就别幻想，哪怕损失10%也果断止损（止损越晚损失越大）。

### 14.6.3 热门股的操作策略和投资要点
- 操作策略：
  1. 冷静观察、及早发现主流热点和龙头；
  2. 先少量建仓争取主动；
  3. **放量突破30日或60日均线后缩量上涨 → 坚决跟进**。
- 投资要点：
  1. 一般个股从启动价算累计升幅**10%~15%**可卖出；可能成为热点的个股升幅达**20%**反而是确认买进时机。
  2. 热点能持续是关键（决定是否续持）。
  3. 热点随大盘**高位放量 + MACD/RSI高位死叉** → 减仓并逐渐退出。

## 14.7 利用股本结构来选股

### 14.7.1 从大盘股中选股的技巧
- 大盘权重股由主流超级资金炒作，有以下特征与对策：
  1. **有惯性**：一旦快速启动不易立即停止，可适当追高获取指标股后半段行情。
  2. **周期长、出货慢**：主力多用反复震荡（圆弧顶或多重顶）出货 → 可利用其炒作特性，在**明显滞涨时逢高卖出**。
  3. **战略眼光**：有/将推出股指期货时，控制左右指数的大盘权重股成为制高点（兵家必争）。

### 14.7.2 从小盘股中选股的技巧
1. 既要看个股股本，也要看**所在板块整体股本**（板块股本少更受投机资金青睐，板块联动明显）。
2. 小盘股**不关注指数**，重点看个股本身（对股指影响小但有丰富短线机会）。
3. **快进快出**：小盘股流通市值小、易被控盘、主力周期短、易受消息面影响；大部分不具长久生命力，仅适合短线参与；选联动效应明显的小盘股。
4. 关注业绩和送配：依赖概念炒作的小盘股会沉寂，业绩优良+送配好的更有涨升潜力。

## 14.8 利用股东人数变动来选股
- **股东人数越少=筹码越集中** → 股价独立性强、走势强悍、常逆势，短线首选；股东人数越多=筹码越分散 → 走势疲软、随大盘。
- 应用：**股东人数开始明显减少时及时介入**；股价涨幅已大、股东人数减少到极限时**果断卖出**（防主力利用指标欺骗）。

### 14.8.2 利用股东人数变动来选股的注意事项
1. **数据滞后**：年报滞后3~4个月、中报滞后1~2个月；须结合这些时段的量能变化判断数据有效性（股价波动不大、量能不巨增则数据较有效）。
2. **股本变动**：配股、增发、送股会影响股东人数与持股数据，须剔除/考虑。
3. **混淆性**：公布的是总持股人数，未分流通/非流通、A/B股，须调整。
4. **欺骗性**：主力可能在期末突击重仓或分仓来误导。
5. **片面性**：股东人数只是个股分析一方面，需配合大盘、政策、资金、业绩、题材等多角度综合分析。

## 14.9 利用比价效应来选股
- 比价效应是推动市场变化的主因之一：牛市初期绩优大盘股价格低廉被追捧→涨高后失去比价优势→二线股接力→三线股/垃圾股→全部涨完牛市休止。

### 14.9.1 具体的比价关系
- 与同比例参照物比价，**选择价格较低（超跌）的个股**：
  1. 同一地域板块内比价；
  2. 同一行业比价；
  3. 同一炒作题材比价；
  4. 相同流通股本规模/股本结构比价；
  5. 与前期的历史高位比（选超跌）；
  6. 与前期的成交密集区比（选超跌）；
  7. 用技术指标（RSI、BIAS、随机指标）作参考选超跌；
  8. 有 H股/B股的与 H股、B股比价（尤其H股）。

### 14.9.2 比价关系的投资要点
- (1) 选目前仍处**底部区域**的股票；
  - (2) 关注市盈率与市净率：**市盈率<25倍，市净率<3倍**；
  - (3) 底部量能特征：**放量收小阳、缩量收小阴**，或**连续小阳** → 后市投资机会较大；
  - (4) **突破密集区缩量回调后介入**资本回报率更高。

## 14.10 利用油价变动来选股
- 油价上涨对下游企业带来成本压力，上游企业获溢价收益；可从**上游企业和新能源股**中把握机会。

### 14.10.1 国际原油基本面
- 长期方向主要看美国执政党：**民主党当政→原油受压**；**共和党当政→原油易涨**（通胀会抬高油价底部）。
- 中期：**欧佩克**减产升价、增产降价；短期受美元指数、飓风等影响。
- 关键：无论原油还是股票，炒的都是**预期**，往往提前反应。

### 14.10.2 利用油价波动选股的技巧
- **煤炭股**：能从油价上涨中略受益（替代关系），但我国煤炭供不应求、关停小矿，产量难大增，受益有限。
- **石油类**：按产业链分，**上游（勘探开发）受益**；**下游（炼油、化工）成本压力受损**；**横跨全产业链**的大型企业（如中石化）内部可转嫁成本、抵抗力强，反而受益。实际选股注意：油田老化、储量降、成本升的上游企业业绩提升与油价无关。油价上涨对**石油化工、纺织、航空、汽车**利空较大。
- **新能源股**：油价上涨刺激替代能源产业发展（生物质能、太阳能、风能等；国内水煤浆、甲醇、二甲醚、乙醇、天然气等），高油价下前景较好。

## 14.11 利用汇率的变动来选股
- 人民币升值预期持续，国际资本流入推动股市走强；不同行业影响不同、股价分化。
- **出口导向型**企业业绩短期受冲击；**以进口原材料为主**的企业因成本降低受益。
- **人民币升值受益板块**（重点关注含H股蓝筹与升值受益概念股）：
  1. **银行股**：本币升值提升银行资产价格（2005-2007牛市龙头）。
  2. **航空股**：燃油成本降低（升值5%→每股收益增超0.1元）+美元外债汇兑收益，最大受益板块之一；交通运输亦受益。
  3. **地产股**：土地稀缺+购买力上升+升值预期，中长期向好、热钱重点方向。
  4. **钢铁股**：进口铁矿石相对变便宜，成本降低受益。
  5. **造纸股**：进口纸浆占成本70%，升值受益。
- **不利对象**：纺织业（成本上升）、汽车股（进口车降价挤压国产车）等依赖出口/受进口冲击行业，及早回避。

## 第15章 抄底策略

## 15.1 底部概述
- 股市底部分长期底部、中期底部、短期底部。

### 15.1.1 长期底部及特征
- 长期底部（大底）形成前提：①导致长期弱势的宏观利空正在改变（最终需消除）；②极低股价水平上投资者信心开始恢复。
- 长期底部特征（9点）：
  1. **投资者普遍亏损**（大多亏损50%以上，主力机构也未能幸免）；
  2. **股指快速下跌**：顶部反转后，连续跌20%也无像样反弹，途中连续巨幅阴线；
  3. **市场大面积跌停**：跌停股可达两市总数的70%以上；
  4. **抗跌股补跌**：强势股/大盘蓝筹/绩优股/基金重仓股开始破位下行；
  5. **股指连续破位**：重要支撑位与整数关口接连被击穿（熊市不言底）；
  6. **股民纷纷离场**：新股民开户下降、旧股民离场；
  7. **融资功能衰竭**：新股/增发减少或停止，此时常有利好但投资者逢高减磅；
  8. **舆论反思不断**：股民对利好充耳不闻、怨声载道，舆论反思抨击；
  9. **末期成交量增加**：下跌超过一年、跌幅超过50%后成交量持续增加=新资金进场；等到想卖的几乎卖光、出现巨大承接力量=临近长期底部。

### 15.1.2 中期底部及特征
- 多在跌势长、跌幅**50%以上**后出现中级反弹；需消息面配合（先借利空加速下跌、再借利好触底反弹）。
- 特征（5点）：
  1. 以半个月~两个月周期形成**头肩底、W底、V形底、圆弧底**；
  2. 股价运行在**45日均线**之上，回调通常**不有效跌破90日均线**；
  3. 回调幅度较深但不超**前面上涨幅度的50%**；
  4. 回调时间通常**不超两个月**；
  5. **上涨有量、回调无量**（抛压轻、主力未出局）。

### 15.1.3 短期底部及特征
- 连续下跌后技术指标超卖出现的反弹转折点，**以V型居多**；探底前常见2~3根大阴线，后现见底K线组合（好友反攻、曙光初现、早晨之星）。
- 特征（5点）：
  1. 日K线常有**长下影线或锤子线**等触底反弹K线；
  2. 股价回落到**5/10/20日均线**时获支撑，或快速上穿5/10日均线；
  3. 回落幅度很小、时间以天计；
  4. 成交量可放可缩，但不改变上升趋势；
  5. 人气旺盛、热点持续、积极看多。

### 15.1.4 别把下跌途中的腰部当底部
- 腰部（非底）形成三种原因：①基金减仓使"底部"成腰部；②主力暗中派发、借反弹出货；③主力快速拉低制造反弹骗短线客接盘出货。
- 区分腰部与底部三法：
  1. 熊市来临/进行中则"底部"不成立；
  2. **未经过下跌有量过程**，底部不现实（卖压未释放）；
  3. 从顶部跌下来**连续跌幅未达40%**，难有像样反弹；即使深跌反弹，后期仍会续跌（底部还在下面）。

## 15.2 抄底策略
- 抄底顺序：先判断大趋势 → 大盘发多头信号 → 再选目标股。

### 15.2.1 判断大趋势
- **大盘趋势**决定机会大小：大机会(上升趋势)大投入、小机会(盘整)小投入、没机会(下跌)不投入；大盘见底后才有抄底机会。
- **个股趋势**：大盘见底后找**先见底的个股**（并非所有股与大盘同时见底）。

### 15.2.2 判断大盘多头信号
- 从政策面、资金面、基本面、技术面四方面判断。
  1. **政策面**：A股政策市特征明显。下跌初期政府不出台刺激政策；政策持续出台+利好堆积、市场逐渐见底，但**政策与见底有时间差**（如印花税降两次仅反弹、4万亿+宽松货币政策才真正见底）。
  2. **资金面**：看货币政策（降息降准→资金净投放）+ 市场资金供给（基金发行、IPO审批速度 + 投资者预期）。货币政策与股市也有时间差，靠累积效应。**资金是股市血液，得资金而雄起，失资金而疲软**。
  3. **基本面**：基本面不能左右股价，**对基本面的预期**才左右股价。股市炒预期。
  4. **技术面**：政策/资金/基本面最终都反映在盘面上，需在盘面得到确认才有意义。技术以趋势技术为核心（趋势、量价、均线、K线、形态、辅助指标），**技术指标的重要度远低于趋势**。
- 一旦确认多头信号即可大胆操作（收益远大于风险）。

### 15.2.3 抄底目标股的选择（5方面）
1. **政策面受益程度**：大盘见底后选受益板块；**政策面与技术面共振**（个股技术上见底/已确立上升趋势 + 政策利好刺激）=大机会。利好作用力越强、时间越长，刺激越大。
2. **资金面关注程度**：资金逐利逐预期；被资金关注的股票会在盘面显示，用技术确认见底后介入。
3. **个股概念情况**：A股喜炒概念/题材；概念足且未被消化就有投机机会；市场见底时**之前跌幅越大的概念股反弹力度越强**。概念股特征：下跌暴跌、上涨暴涨（力合股份跌90%后涨500%）。
4. **是否有业绩改善预期**：有业绩大幅提升预期的股票迎来上涨机会。
5. **技术面见底**：**只有技术面见底才是真正见底**（只有市场走出的底部才是真底部）；大盘见底后须先确认个股已在底部才买入，否则买入是盲目有风险的。

## 15.3 利用K线和成交量识底和抄底
- 长期大幅下跌后，K线出现带较长上下影线的**小阴线、小阳线或长十字线** + 成交量放大 → 预示止跌回升。
- 长期大跌后横向盘整有3种可能：返身向上（最理想）、继续向下（最差）、长期横盘半死不活（资金被搁死）。
- **主力吸筹确认**：历史低位K线出现上下影线小阴/小阳/长十字 + **温和放大**成交量，持续几周甚至更久且股价在狭小范围波动 → 确认主力吸筹，密切关注；大资金可先建小仓，股价向上拉升时加仓；被套者不必急于割肉。
- **注意**：不要因股价从高位跌许多就急于买进（易买在次高位被套）。须把当前股价与历史最低价比较，**长期大幅下跌后接近或跌破历史最低价**才确认处于历史低位。

## 15.4 利用K线和均线识底和抄底
- 大盘长期大跌后突然拉大阳线，结合**10日均线**判断反弹力度：
  - **大阳线连10日均线都没摸到** → 难成大级别反弹/反转，盲目抄底风险大（除非短线高手严格止损才用少量资金）。
  - **大阳线直接冲上10日均线**并围绕其震荡、**量能不萎缩** → 可能形成阶段性小底，有中短线抢反弹空间，介入盈利可能大。
- 中长期大底多在较长时间下跌后**突破性放量大涨、一下摸高至10日均线之上**。
- **30月均线与月K线实体相交**后（历史上多为相交后**5个月**）见底回升；历史上6次相交5次在5个月后发生大级别反弹。相交后不久基本见底回升。

## 15.5 利用大跌后再加速下跌识底和抄底
- 长期下跌后散户深套绝望、心理防线崩溃时，往往是**主力进场承接之际**。
- 加速下跌甚至**跌破重要前低/历史大底**时不要恐慌割肉，而应意识到赚大钱机会来了（主力制造空头陷阱逼散户交出筹码）。
- 老股民"跌时不卖、反弹就出局"会被反复踏空；主力借反弹出货，之后追高又买在阶段高点。

## 15.6 利用时间识底和抄底技巧
- **时间规律1**：沪深股市有**13~20个月见底**规律，从高位到低位一般经**16个月**出现见底回升（例：18/16/20/15/13个月）。
  → 连续下跌16个月左右开始重点关注大盘，注意K线形态、成交量、标志性K线、重要指标是否**底背离**、下降趋势线是否被**有效突破**；出现明显做多信号→重仓买进（风险小收益大）。
- **时间规律2**：大盘**连续下跌4~6个月**后很可能出现底部反（多短期底，更多是中期/长期底），宜加大关注。
  - 应用：用少量资金试探性建仓，大势一致再加仓，不一致则止损出局（控制风险）。

## 15.7 利用对称规律识底和抄底技巧
- 股市涨跌存在对称关系：**大涨之后必有大跌，大跌之后必有大涨**；重要点位/价位会"周期轮回"重现（从哪里来回哪里去）。
- 大盘重要点位附近会有相应"点"与之共存（如 400/500/1000/1300点多次轮回）；个股也如此（宝钢3元↔8元↔22元轮回）。

## 15.8 利用价值投资识底和抄底技巧
- 价值投资=市场价格远低于内在价值时买入（如拿5角买1元）。投资价值分现在价值（用市盈率衡，越低越高）与未来价值（公司发展空间、高管素质、整合预期等，非市盈率可体现）。
- 判断价格低于内在价值往往：
  - 整个股市**平均市盈率接近或低于历史最低水平**，或接近/低于国际股市平均市盈率；
  - 绝大部分股价**接近或低于每股净资产**；
  - 平均分红所得**低于同期银行一年期利率**。
- **看的是整个股市平均市盈率，不是个股**。海外成熟股市：大盘平均市盈率跌到某一低位就跌不下去=价值凸现即将见底（如香港恒生指数**13~15倍市盈率**为下跌底线，附近买进赢多输少）。

## 第16章 逃顶策略

## 16.1 顶部概述
- "底部三月，顶部三天"——**底部运行时间长、顶部运行时间短**。顶部特征分政策、市场、利好、技术四方面。

### 16.1.1 政策顶部特征
- A股是典型政策市，许多头部由**政策调控**造成：上调印花税、公布新股额度、严禁国企炒股、国有股减持、大小非减持+大盘IPO、宏观调控等（1996/1997/2001/2007 大顶均为政策顶）。
- 逃顶须**广泛搜集并精心分析政策信息**，及时发现管理层调控意图，领先市场一步。

### 16.1.2 顶部市场特征
- 当媒体到处是暴涨/财富神话、买菜大妈谈股价、证券报买不到、银行排队买基金（老大妈老大爷）、开户排长队、新股民互相荐股、遍地自称股神、报告会人满为患时 → **股市接近顶部**。
- 市场不可能让每个人赚钱；当多数人争先买股时就是大资金撤离之时。要"人弃我取，人取我予"。

### 16.1.3 利好顶部特征
- 个股对利好有预见性：主力利用未公开的**重大利好低位吸货→拉升→高位借兑现机会派发**，即"**见光死**"。利好兑现往往是出货时机。

### 16.1.4 顶部技术特征
1. 顶部反转形态：高位**头肩顶、双顶、圆顶、尖顶、向下跳空缺口、顶部岛形反转**都是明显顶部信号；
2. 涨幅已大时，**5日均线下穿10日均线（死叉）且股价跌破20日均线** → 至少形成阶段性顶部；
3. 高位出现**穿头破脚、身怀六甲、黄昏十字星、黄昏之星、长十字线、螺旋桨** → 很可能已见顶；
4. 股价**跌破长期上升趋势线** → 很可能已见顶；
5. **MACD高位死亡交叉** → 很可能已见顶。
- **逃顶要果断坚决**：发现信号毫不犹豫卖出（卖错了还能再战，错过则致命）。

### 16.1.5 别把上涨途中的腰部当头部
- 腰部（非顶）形成三种原因：①主力顺势打压清除短线获利盘后继续拉升；②主力减仓+换手提高持股成本后继续上；③主力第一波拉升后休整，伺机发动第二波主升浪。
- 区分腰部与顶部三法：
  1. 基本面看行情不应只到这里就结束 → 往往非头部；
  2. **上涨有量、下跌无量**，能量形态好 → 往往非头部；
  3. 主力刻意打压痕迹明显 → 往往非头部。

## 16.2 逃顶策略

### 16.2.1 判断大趋势
- 先判大盘：牛市多头趋势可放心操作；熊市空头趋势小心、避免大额投入。再判个股趋势以决定操作方式。正确判断大盘+个股趋势 → 提高资金利用率。

### 16.2.2 判断涨幅
- 短期涨幅过大且**明显异常放量** → 不盲目追高；低位介入已快速拉升、涨幅巨大、大量获利 → **落袋为安**。
- 分辨三种个股运作模式：
  1. **牛市龙头板块龙头股**：启动最早、涨幅最大、操盘凌厉、领先大盘，通常率先突破历史最高点（上方无压力可涨几十倍）。操作要判断准大盘+个股大趋势，突破前高后涨幅常以倍数计算。
  2. **蓝筹股**：牛市中坚、市场旗帜；一线蓝筹涨幅往往小于二线蓝筹（二线总股本更小好操作）。蓝筹多**波段操作**，涨速小但稳健、相对安全。
  3. **纯概念股**：波动极大，快速拉升再快速出货、最易套牢。避免过度贪婪，出现不稳定出货行情及时抛出；大环境好可向相对高点靠，环境不好勿期望过高。出现**V形尖顶放巨量巨幅震荡**要快速逃离。

### 16.2.3 发现空头信号
- 大涨后真正暴跌前一般会发出明显空头信号。快速拉升的个股空头信号时间短、很快转跌；趋势运行时间长的个股逃离时间充裕（大资金比小资金持久，公募/社保比私募/游资持久）。
- 空头信号从三方面确认：①整体趋势中 **K线和成交量**；②是否形成**顶部形态**；③技术指标是否**发出卖出信号**。

## 16.3 利用市场人气识顶和逃顶
- **鞋童定律**：当人人都在谈论股票时，正是卖出股票离场之际（1929年老肯尼迪擦鞋童故事）。
- 人气见顶表现：①**大盘股集体起舞**（大象群舞，连涨数月，历史上罕见）；②**超级大盘股挤上全球市值前10**（投机过重）；③**抢购基金热潮**（逢基必抢、买基必盈共识）。
- 高手从人气极度沸腾意识到高风险而看淡抛股；新股民盲目做多见多陷入大风险。

## 16.4 利用成交量识顶和逃顶
- **大涨后放大量**（无论收阴收阳）不久下跌概率非常大；即使牛市也是如此。**"天量天价"**：出现历史天量=见顶（准确率相当高）。
- 判断"涨高了"：**大盘见底回升15%以上；大盘股离最低价20%以上；中盘股30%以上；小盘股40%以上**（牛市个股涨30%~200%屡见，需按实际）。
- 判断"放大量"：成交量一般为**低迷时的3倍以上**（通常要4、5、6倍），且成交量放大到某种程度后**股价涨不动甚至小幅回落、量不再增反减** → 阶段顶可能性大。
- **弱市反弹放量 = 主力制造虚假繁荣减仓**（不是场外资金介入），应果断出局否则被套半山腰；应回避集中放量的股票/板块；大盘整体放量=被套大资金集中出逃，尽早出局。

## 16.5 利用大涨后再加速上涨识顶和逃顶
- "**行情在欢乐中结束**"——行情大涨之后**再加速上涨** = 欢乐到顶点，及时离场。
- 经长期大幅上涨后出现**加速上涨、创历史新高、市场叫好**时要警惕：
  - 大盘**越涨越慢** → 开始逢高派发；
  - 大盘**滞涨横向盘整** → 抛出大部分筹码或清仓（不贪最后一段"鱼尾"）；
  - 大盘**回落至上周最低点指数下方** → 果断止损/止盈出局，耐心等下一轮。

## 16.6 利用周巨阳线识顶和逃顶
- **周巨阳线**（以往很少见的超长实体周大阳线）= 短期超涨，多为市场炒作而非基本面实质变化，之后会受市场报复。
- **周巨阳线后走势大概率不妙，不论下有缺口与否都警惕**。
- 研判（质地好可短期见顶=大幅回调后主力再拉起；题材虚炒作则中长期看空）：
  1. **回调超过实体三分之一** → 减仓（下跌可能增大，抛部分筹码）；
  2. **回调超过实体二分之一** → 清仓（继续暴跌概率增至**85%以上**）；
  3. **回调不超过三分之一但盘整时间长** → 减仓（主力可能在盘整中悄悄出货）；盘整**不超过一个月**（周线4根K线）即高度警惕、果断撤离；
  4. 巨阳线上方出现小阳线/阴线但**成交量明显萎缩** → 可能有潜在利好、可暂持仓，设好止损；
  5. 巨阳线后股价用**小阳线不断向上攻** → 主力仍看多、可能有利好，可暂持仓观察，设好止损。

## 16.7 利用月巨阳线识顶和逃顶
- **月巨阳线** = 罕见的超长实体月大阳线，见顶信号**比周巨阳线更强**（一月透支未来几个月/几年行情）。
- 月巨阳线实体越长见顶信号越明显；**加速上涨或以"叠罗汉"形式出现**（连续两根巨阳叠加）→ 中长期见顶即将来临。
- 按实体长度操作：
  - 实体相当于涨幅的**50%~100%**（非超长）→ 可多观察一段时间再决定；
  - 实体相当于涨幅的**100%以上**（超级巨阳）→ 先抛出一部分筹码锁定利润再视情况。
- **月巨阳线上影线超过实体1/3 → 果断清仓**。

## 第17章 跟庄炒股

## 17.1 庄家概述

### 17.1.2 庄家的分类
- **按持股时间**：
  - **短庄**：周期2天~30天；重势/概念/形态、持仓少、严格止损；控盘1%~10%，建仓1~10天。
  - **中庄**：周期约一个中级上升趋势（牛市3~6个月、熊市反弹1~2个月）；控盘10%~30%，建仓10~30天。
  - **长庄**：周期约一个牛市始末（基本面不恶化可长持+少量波段）；控盘10%~50%，建仓1月~12月。
- **按坐庄家数**：单独庄（控盘30%~70%，走势有规律）、合伙庄（基本面好、流通盘大）。
- **按入驻时间**：新庄（介入新股/老庄撤出已久的个股）、老庄（熟悉股性、把握较好）。
- **按股价强弱**：强庄（资金雄厚、控盘高、特立独行、强于大盘、基本面向好）、弱庄（资金弱、靠做波段、看大盘脸色）。
- **按驻留**：常驻庄（长期高抛低吸）、游走庄（爆发/题材行情时做足一次就走）。

## 17.2 庄家准备阶段

### 17.2.1 准备阶段的常识（筹码/利润/消息）
- **筹码常识**（流通盘结构）：长期锁定20%（很难出售）+ 最活跃浮动筹码30%（涨跌波动卖出）+ 中长线持有50%（其中20%长线持有、20%上涨时卖、10%下跌时卖）。
  - 庄家只要**控制30%筹码基本可控制股价走势；控制50%筹码=高度控盘，可轻松操纵**。
  - 底部反复震荡可收集30%活跃筹码→达50%→加长期筹码达70%→拉升抛压轻。
- **利润常识**：股价翻倍，庄家净利率仅约20%（建仓区域成本抬高、出货均价压低、印花税佣金10%+宣传合作等10%+借款利息10%）。**控盘30%时股价上涨100%是最低拉升目标**，否则难保本。
- **消息常识**：建仓时消息严格封锁；**出货前大量散布消息**。消息按 内部→关系户→大户股评→社会公众 顺序传播；散户接到的消息往往是庄家出货的最后阶段（**勿轻信散户得到的庄股消息**）。

### 17.2.2 资金的安排
- 坐庄资金分：**建仓资金**（自有资金、底部低价区买股）、**拉抬资金**（推高股价，数量不大，仅承接外部流动筹码；同板块需比例分配、非同板块可轮番拉抬）、**预备资金**（预防突发危机）。
- 资金性质决定走势：**自有资金→坐长庄、慢牛缓慢推升**；**拆借资金→坐短/中线、大起大落**。
- 筹码锁得多、流动资金少 → 无短期暴涨暴跌；短炒资金充裕 → 涨得猛跌得快（从哪里来回哪里去）。

### 17.2.3 坐庄的过程
- 三步曲（核心，任何手法都离不开）：**建仓、拉升、出货**。
- 完整过程可细分为：建仓前试盘、建仓、拉升前试盘、洗盘、拉升、(再洗盘/试盘/拉升循环)、出货、反弹出货、快速出货、扫尾。
- 各阶段要点：建仓=时间价格区间受限+隐蔽；试盘=测抛盘/跟风盘；洗盘=洗掉跟风、最后搜集；拉升=快速脱离成本区；出货=猛烈快速、干净利落。

### 17.2.5 坐庄的时机
- 庄家入庄时机（供散户识别庄家进场）：
  1. **熊市末期**（市场跌无可跌、宏观/政策回暖）逢低吸纳（收集的是底部筹码）；
  2. **大行情来临时**常发利空大量吃货建仓；
  3. 大行情中**市场调整时**建仓；
  4. 熊市中**个股严重超跌（跌幅超50%）**时入场（锁价格偏低、跌速过快的股）；
  5. 上市公司**基本面重大改观但未被市场发现**时提前介入（散户抬轿、主力坐轿）；
  6. **新股入市**时介入（无庄、无套牢盘、公积金高、流通盘小、股本扩张强）。

## 17.3 庄家试盘的技巧

### 17.3.1 试盘的作用
- 试盘目的：①了解是否已有庄家；②了解筹码分布（上档套牢盘/获利盘抛压、下档买盘支撑）；③先少量买进用于打压的筹码（试盘时成交量会突然放大、股价短暂上升）。
- 若成本过高庄家会放弃坐庄（安全第一、获利第二）。

### 17.3.2 向上试盘
- 毫无征兆突然快速拉升然后让其自由回落，测抛压：抛盘多→未到底可打压低位吸筹；抛盘少→需拉高建仓加大成本。

### 17.3.3 向下试盘
- 有准备用少量筹码突然向下大幅打低，观察恐慌盘吐出量/场外买盘兴趣，确定打压极限（出现长下影线）。
- **判断庄家试盘/建仓的必要条件：日K线中30日均线已走平或即将从下向上走平**。

## 17.4 庄家建仓的技巧

### 17.4.1 庄家建仓的本质
- 建仓初期庄家用迷惑/恐吓/诱骗让散户抛筹：放利空、K线现见顶/卖出信号、假黄金交叉、假量、MACD卖出信号。
- **建仓初期勿急跟**，否则易被洗出或"看明白却等不及而逢高卖出"，错过黑马。

### 17.4.2 横盘式建仓
- 长期大幅下跌后股价平稳横向盘整，形成**平台或箱形底**，时间一两个月到半年以上。
- **横有多长，竖有多高**：低位长期横盘股票一旦启动涨幅惊人，中长期投资者可耐心选择。

### 17.4.3 缓升式建仓（推高式/边拉边吸）
- 股价被市场推高脱离底部、惜售，只能逐步推高收集；日K线**进二退一或进三退一**。庄家成本较高、风险较大，须配合丰富市场题材。

### 17.4.4 缓跌式建仓（边打压边吸筹）
- 多用于冷门股/长期下跌股，呈小阴小阳下行，被市场遗忘。

### 17.4.5 反弹式建仓
- 下跌低点后庄家无法底部吸够筹码，利用投资者"反弹出货""高抛低吸"心理，反弹高点回收筹码后大幅拉升。

### 17.4.6 打压式建仓
- 庄家已有少量筹码后不计成本大幅打压，制造直线暴跌，散户崩溃抛筹庄家一笑纳；多用于大势调整或利空时。**底部时间不长**（怕散户明白后抢筹）。

## 17.5 庄家拉高的技巧
- 成分**初期拉高、中期拉高、最后拉高**三阶段。

### 17.5.1 初期拉高
- 目的：①快速脱离成本区进安全区；②再吃筹码建中段仓。特征：均线/指标快速修复成**多头排列**、**成交量明显放大**（散户套牢者看到大涨纷纷出货，被洗出）。

### 17.5.2 中期拉高
- 前半段继续吃货+跟风盘进出→成交量**温和放大**；后期浮筹洗完、仓位达标→**成交量萎缩**（凭上冲力量拉高）。
- **中期拉高过程中若出现放大量，要小心庄家提前出货**。

### 17.5.3 最后拉高（末期拉高）
- **唯一目的就是出货**：股价快速拉升，有筹码者舍不得卖、无筹码者追进被套。
- **末期拉高时成交量急剧放大=主力出货可能性最大**，不要信"价升量增后期看涨"，应清仓逃命。**顶部放量是绝对危险信号**。

## 17.6 庄家出货的技巧
- 出货最重要也最保密，不能靠消息/信息判断，只能靠经验和技术估测。大势向好→庄家预谋有计划悄悄派发；资金问题→直接边拉升边出货；重大利空/系统风险→不计成本凶狠砸盘出货。
- 出货方式7种：

### 17.6.1 拉高出货
- 使用频率最高。股价已超目标价位10%以上，高位对倒放量（主动买盘假象），**少吃多卖**（买5万卖35万）把筹码交给跟风盘。
- **特征**：快速拉高前股价相对平稳上升→某日快速拉高放大量→横盘（量中平/量大平）→**重心下移**。
- **应对**：股价**击破快速拉升的起点第一时间出逃**；拉高后放大量、高位盘整量中平/量大平→出逃。

### 17.6.2 涨停出货
- 拉升最后阶段拉涨停（一根或多根）制造强势让散户冲进。**涨停时主力撤掉自己大买单让下方散户买单成交**（出货）。
- **应变**：股价有涨幅+涨停+成交量较大→散户勿进；涨停后量突然放大+后续盘整放量→确认出货。

### 17.6.3 缓攻出货
- 拉高出完第一批货后缓缓上攻出货：买盘位堆大单、卖盘位放不显眼小卖盘，维持股价缓慢上升（可持续长达1个月）。大量买单诱惑散户冲进。

### 17.6.4 打压出货
- 大势不好/资金不允许时：目标区某日大幅高开后立即出货，买盘出现即砸掉，甚至杀到跌停。

### 17.6.5 小单缓跌出货
- 时间充裕+大势好：每天只卖两三千股，重心缓缓下移（可历时5个月）→**跌起来没有头，早早出局**。

### 17.6.6 震荡出货
- 高位区域横盘震荡出货（可3个月），很具迷惑性，技术难以判断（周线/月线也难判）。

### 17.6.7 反弹出货
- 主力货大部分出完只剩少量时，大幅下跌后利用**乖离率过大**提示诱惑抢反弹短线客，触及上方均线时出逃，之后股价不断下跌。**大幅下跌行情中做反弹要小心，一般投资者不做为妙**。

## 17.7 庄家洗盘的技巧
- 洗盘是坐庄次要阶段，有的庄家省去。

### 17.7.1 向下洗盘
- 上涨初期股价小幅上涨后突然以单根中阴线或几根小阴线组合吓唬获利盘出局。**打压位置常为20日或30日均线**。
- **中后期主力一般不向下洗盘**（怕引发系统性风险即筹码松动）。

### 17.7.2 横向整理洗盘
- 拉升到一定高度后停止拉升、较长时间小幅震荡横盘（不理会大盘涨跌），利用不知方向的迷茫逼筹。用于**中期拉升阶段、大盘良好**时。初期拉升阶段不用（浪费时间损资金利用率、老股民会看穿抢筹）。

### 17.7.3 向上洗盘（拉高洗盘）
- 大盘极强、散户做多热情高涨（向下/横盘诱空筹码收不回），或资金时间紧迫时必须速战速决时采用。**特征：向上攻击同时伴随短线剧烈震荡**，逼出获利盘、吓出止盈盘、折腾出短线止损盘。

### 17.7.4 洗盘与出货的区别（8方面定量鉴别）
1. **庄家心理出货价位**：每只股上涨有心理出货价。预测：比价效应（质地相同股票见顶价基本相同）；按机构/股评目标价打折（特强牛市9折、较强市8折、一般市6折）。
2. **震荡幅度**：洗盘幅度小（弄坏技术图主力反而麻烦）；**出货震幅大**（不留图形、吸引短线客浑水摸鱼）。
3. **震荡时间**：**久盘必跌**。洗盘约1个月（最长2个月）；**出货可长达半年以上**。
4. **震荡次数**：洗盘震荡一般**不超过3次**；出货次数无所谓。
5. **换手率**：洗盘换手率不高（筹码不大换班）；**出货换手率高**（主力筹码全交散户）。
6. **大阳/大阴线多少**：**出货时多**（拉大阳诱多再杀跌出大阴）；**洗盘少**，以小阳小阴为主。
7. **均线支撑**：**洗盘在30/60日均线处强支撑**（低吸获利）；出货不太在意均线，但可能在120日(半年)/250日(年)线反弹，一般勿参与。口诀"主力做盘看线=往上做；不看线=往下做"。
8. **震荡后突破方向（最关键）**：
  - **洗盘→向上突破**：突破前高站稳**至少3天**、涨幅**超3%**、**成交量明显放大**。注意**假向上突破**（突破前高后又回落到前高之下→果断清仓）。
  - **出货→向下突破**：收盘价**至少3天**在前低之下、跌幅**超3%**。注意**空头陷阱**（向下突破后转头向上攀升则不卖）。

## 17.8 庄家被套自救的技巧
- 庄家被套主因：政策突变、介入太深、行情走极端、操作失误。
- **自救方式4种**（均诱散户接盘，散户应识别规避）：
  1. **推进式（缓升式）**：不理会大盘缓慢推升、成交量放大、连续小阳或两阳一阴；利用散户赶底心理，庄家边推边出货。
  2. **拉升式**：大幅下跌后止跌掉头，连续中阳/大阳向上拉、量放大（力度大），拉升结束再入熊途；庄家不敢拉太高不断抛售出局。
  3. **波段式**：有节奏波浪上行，每波上涨都抛一部分筹码，洗盘再拉起，诱散户波段进出。
  4. **利好式**：用题材/消息营造买气（非技术/实力），引股价高开实现撤退。

## 17.9 跟庄炒股注意事项

### 17.9.1 了解联合坐庄（基金）
- 联合坐庄特点：炒作**真实业绩/公开价值**（非虚假题材）、依次跟进/结队而行/先知先撤、只靠研究水平不追求资金优势。
- 缺点：只能同富贵不能共患难（调整时夺路而逃）、**羊群效应明显（涨跌都一边倒）**、常价值严重透支有强烈回归要求。

### 17.9.2 选择强庄（特点可量化）
1. **总比大盘强**：大盘涨时比大盘涨得多、跌时抗跌（筹码多、流动筹码少、易涨不易跌）；
2. **总比同板块强**：是板块"领头羊"，走势强于同板块其他股；
3. **我行我素**：逆市而动（独立于大盘）=阶段性强庄或牛股；
4. **轻松应对利空**：利空时能接纳大量抛单、控住股价跌势（弱庄则随波逐流下跌）。

### 17.9.3 跟庄其他注意事项
- ①摸清庄家性质（一流创造机会题材、二流追寻模仿、三流等待；基金/游资、长/中/短庄）；②保持独立研判（警惕所有概念/消息/图形/指标，庄家从头到尾有欺骗性）；③保持稳定心态（有耐心等待、细查真假、果断参与、敢止损、无机会时快速离场）；④熟悉庄家手法；⑤资金量不大可用游击战术跟紧庄家吃掉主要拉升波段；⑥非短线不必每日看盘（天天看盘难免患得患失）。
- **庄家也常失败（失败概率约40%）**，牛市中成功率高，大熊市中多数中长庄被消灭；不能盲目相信庄家，要有自己的判断。

## 第20章 涨停板策略

## 20.1 涨停板概述
- 规则：普通股涨跌幅**10%**、ST股**5%**、新股上市首日不限。
- 涨停/跌停是市场极端的非正常走势，往往是巨大机会或风险的来临。题材越强越易追到涨停；**除非极大利好，否则单靠散户难以封住涨停**（涨停常是主力运作结果）。
- **注意**：主力出货≠主力出局。主力可能为维护股价而增减仓；出局与否看大环境与个股基本面是否还有深挖空间。

### 20.1.1 涨停板交易的机会
- **市场机会**：牛市；熊市末期超跌反弹；板块集体走强；重大影响新概念出现 → 涨停机会多。
- **个股机会**：
  - **行情启动**（长期整理后底部拉升/超跌反弹启动）——难把握但获利丰厚；
  - **行情进行中**（主升浪）——机会最多，超级强势股连续涨停，**是涨停操作最佳时机**；
  - **行情末端**——机会少、风险大。

### 20.1.2 涨停板交易的风险
- 行情启动初期买入→可能是主力试盘，次日被拖入调整亏损出局；
- 拉升阶段买入→可能立即回调（边拉边洗），资金使用效率低；
- **行情末端买入（看错行情，把末端当中部）→ 当日即亏20%，次日无法出局，第三天亏30%以上**。

## 20.2 涨停板的类型

### 20.2.1 一字型涨停
- 特征：开盘即涨停并封到收盘（无封不牢）。
- **低位一字型**：反映主力拉升意图（快速脱离建仓区）；底部持股惜售、少量资金即可封涨停；会最先进入"今日涨幅排名"吸引跟风盘。
- **大幅拉升后一字型**：主力拉升到位，第二天高开出货（连续一字后高开极大阴线）。
- **提醒**：第一个一字型涨停能及时介入，第二交易日会有不错盈利。

### 20.2.2 T字型涨停
- 特征：开盘涨停→中途打开→再封到收盘。
- **吸筹**（多在新股建仓中）：涨停途中"买盘支撑不住"打开板诱抛盘出来，最后快速抢筹封死。
- **减仓或减压**（连续上涨后）：利用惜售局面趁人不备快速开缺口减仓。观察要点：
  - 缺口只有一个 → 看缺口深度，过深=抛压巨大；
  - 缺口有几个 → 主力陆续减仓；
  - 当日成交量过大 → 主力加大减仓力度。
- 主力减仓动作不大时难分减仓/减压，但只要主力露出"不需要过多筹码"信息，**后期拉升空间有限**。
- 涨停处缺口介入可得部分利润，但**不及时出局可能被套**。

### 20.2.3 拉高型涨停
- 特征：低开/平开/高开后，收盘前被封涨停。基本类型：**斜推式、平台整理式**（及两者演变）。
- **一字型**暴露主力不希望市场跟风（连续一字=建仓完毕、快速脱离成本区盈利）；拉出**2~4个一字板**后多用 T字型/拉高型吸引跟风。若涨幅过大，**暴涨背后是暴跌**（主力速战速决）。
- **拉高型**一开始就透露主力希望市场跟风：边拉升边吸筹边洗盘，提高参与者成本、过滤浮筹、激活人气。后期**出货缓慢**，常高位**小幅/宽幅震荡出货**。

## 20.3 解析涨停封不牢现象
- 特征：①高开盘吸引关注；②一度急拉诱多涨停；③封板后屡次打开。
- 三种原因：减仓/减压（阶段性顶部）、试盘/洗盘（上涨中途）、拉高吸筹（阶段性底部）。

### 20.3.1 涨停封不牢为减仓或减压
- 利用散户"涨停=跟风机会"心理，主力**悄悄撤掉买一接盘项让散户买单顶上，照买一价快速出货**，反复撤单/推板/再撤 → 封不牢。
- 需借强势大盘或个股利好环境麻痹散户；此时股价往往已不低、主力获利丰厚。
- **"狼来了"警告信号**：连拉涨停大阳线，前1~2次封不牢但收盘封住（诱多），第3次封不牢且收盘不封 → 主力套牢追高者。**累计升幅较大后见涨停封不牢要准备出货**：跌破均价线或第二波跌幅过深→稳健者等**破5日均线**出局、中线者等**破30日均线**出局。
- 主力也可能低开再拉升吸引跟风+急拉令抛盘惜售，然后撤买单大单抛售至跌停。

### 20.3.2 涨停封不牢为试盘或洗盘
- 在即将拉升或关键阻力区，主力试盘测跟风/抛压：买盘多→顺势上攻；卖盘多→停止拉升、清理浮筹；大盘不好→借势打开涨停洗盘（缺口不深、几分钟填回）。
- 试盘时若**成交量放得过大** → 卖压压力太大、主力可能调整，短线客及时减仓（可守5日均线）、中线守30日均线。

### 20.3.3 涨停封不牢为吸筹
- 阶段性底部、低位难吸筹时主力拉高吸筹：拉涨停→打开板制造恐慌抛售→低位接筹再封。**涨停封不牢是主力拉高建仓特有现象，但股价须在相对低位**。
- **防超级短庄**：低位拉涨停后抛盘不大→次日高开快速出货；抛盘过大→次日低开低走、主力斩仓出局。一般短庄调整几天后创新高；强庄后期必有拉升。

## 20.4 拉高型涨停股的交易时机
- 熊市/震荡市大盘大幅下跌或横盘震荡时，**率先涨停的股票透露主流资金最新动向/炒作方向**（主力有备而来、实力强、可能成热点领涨）。追击涨停板、强势股成为工作重点。

### 20.4.1 拉高型涨停股的介入点
- **最强买点**（一字型）：开盘时（难买到）。
- **拉高型介入条件**：开盘高开 + **5分钟内**即拉涨停 + 大盘向好 + 个股涨幅不太大 → 短线可加仓跟进，**仓位不超30%**（追涨停有风险：当天打开出货或次日低开）。
- 好操作约赚20%~30%，操作不好也有约10%。
- 上升趋势+涨幅不大的，高开后**回调不破5日均线不出**。
- 介入点常为**突破前期波动高点**；上拉速度大可能买不到，只能买涨停价。
- 涨停时间越短变数越少、涨停招数越少；随之后封板方式增多。
- 介入须综合大盘趋势、个股趋势、主力手法、盘口变化判断。

### 20.4.2 拉高型涨停股的介入注意事项（13条）
1. 密切关注**高开2%以上**的股票（缩短与涨停差距、提示快奔涨停）。
2. 高开2%以上时快速查看 K线/均线/量/挂盘/流通盘/市盈率/首笔成交量/板块/信息雷达，分析高低位、趋势、主力意图、性价比。
3. 并非所有拉高型都能介入（开盘即涨停防不胜防），调整心态**捕捉第二个涨停板**（一支涨停后常有第二支）。
4. **越早封涨停越有冲劲**、续涨可能越大（主力有备而来），介入难度大、须眼疾手快拉大委买价。
5. **9:40后**的快速拉涨停，多数是试盘或诱多减仓（有备而来则板不会被打开；试盘见势不好撤手走人；诱多减仓任何时候都减仓）。
6. **10:00~11:00**多数主力见大势而动、展开进攻，此时追涨风险较小（但须判准大盘持续偏好）。
7. **10:00后**趋势渐明朗：与涨停还有**5%差距**，即使大角度冲板，中途稍有停顿即被抛盘压回；除非几分钟直接封板，否则后期难免整理。
8. **10:00后台阶式上涨**（距涨停不近）：等待**爆发性成交量+股价创分时当日新高**才进——**高涨幅+大角度+大成交量三条件缺一不可**；10:00后看大盘/板块脸色。
9. 前期**平台整理理想且距涨停5%以内空间**时，**14:30前**可保持关注（可能冲向涨停）；其后冲板无多大追进价值。
10. **14:30后急涨**不轻易跟风，除非大盘后半场突发利好；利好多头介入次日有后知后觉者抬升。
11. **越晚封涨停越无价值**（多属市场跟风或短线抢盘）；主力愿继续拉高则还有行情，否则无价值。
12. **斜推式**若距涨停不近，往往不会快速涨停=主力强势吸筹；虽进入时机多，但后续主力可能反手洗盘（洗掉当日跟风者）。
13. 股价**刚冲到涨停又滑落** = 主力出货或卖压确实大，后期难有表现（若主力涨停吸筹，会先封一段时间再打开的恐慌抛售假象，不会刚冲即滑）。

> **涨停失败常见原因**：大盘不配合、板块不吸人气、主力诱多、主力试盘，尤其与股价高低位置有关。

## 20.5 涨停板交易注意事项
- 意义在把握**涨停后续的市场机会**（不只追逐涨停本身）。开盘即涨停虽难介入，但常有后续上涨势头，可追踪在合适位置介入。
- 选**早涨停**的个股，注意风险与主力意图，见势不好就走。
- 三点：
  - 上涨势头好的涨停板，被打开次数**不超2次**、打开时间不长、缺口不深（市场一致看好）；
  - **虚假涨停**：虽有巨大封单量，但常在大盘不济时突然撤单或被更大抛盘吞没、板迅速打开——**不要因封单量大就看好后势**；
  - **涨停被打开次数过多** = 行情趋弱或主力吸筹/减仓，绝非快速拉升迹象，不慎介入及时出局。

## 20.6 涨停板敢死队

### 20.6.1 涨停板敢死队概述
- 指善做短线的超级大户，通过短期快速拉升股价赚差价（游资代表，震荡/熊市中活跃）。主力常狙击他们（如心电图型出货套牢敢死队）。敢死队屡屡亏损。

### 20.6.2 涨停板敢死队的操盘手法
1. **预测市场，就势引导**：借用/预测朦胧概念的市场效应，四两拨千斤。
2. **重视消息，选股有序**：选**上升趋势加速阶段的极强势股**或**远离套牢区超跌的极弱势股**，或基本面/题材对股价影响重大的股，按题材可操作性排序。
3. **有庄无庄，照炒无误**：绩优被埋没股抢在主力拉升前突袭；冷门股直接拉涨停。
4. **盘小优先，低价优先**：多选**5亿股流通盘以内且价格较低**的股（两个涨停承接5%~10%筹码资金可承受）。
5. **随行入市，可长可短**：抓准时机敢持仓半月，连续拉升+洗盘，涨幅甚至达100%；若仅随行市短线操作，则次日按计划出局。
- 一旦冲上涨停板常挂**巨量买盘**稳定人心吸引后继；大盘明显走弱则**撤单**、次日开盘**斩仓出局**。
