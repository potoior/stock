# 《半小时漫画股票实战法》精确量化参数提取

> 本书所有策略的精确参数、阈值、操作方法梳理

---

## 一、技术指标

### 1. MACD (12, 26, 9)
- **标准参数**: (12, 26, 9)
- **金叉**: DIFF 上穿 DEA，绿柱转红柱
- **死叉**: DIFF 下穿 DEA，红柱转绿柱
- **零上金叉**: DIFF/DEA 在零轴线上方 → 新一波大涨
- **零下金叉**: DIFF/DEA 在零轴线下方 → 只是反弹，可靠性低
- **多次零下金叉**: 二次或多次金叉 → 可靠性大大提高
- **零上死叉**: 多头市场回调，可靠性不高
- **零下死叉**: 新一波下跌开始，可靠性极高

**三板斧抄底术**:
1. 经过一波下跌后反弹
2. 股价再次下跌创新低
3. MACD的DIFF线低点不创新低（底背离）
4. MACD金叉确认底背离 → 买入信号

**抓主升**:
1. 一波上涨后调整
2. 股价调整不破前低
3. MACD在略高于零轴线位置金叉
4. 出中阳K线 → 买入信号

**逃顶术**:
1. 一波上涨后调整
2. 股价第二波上涨创新高
3. MACD的DIFF线高点未创新高（顶背离）
4. MACD死叉确认顶背离 → 卖出信号

### 2. KDJ (9, 3, 3)
- **标准参数**: (9, 3, 3)
- **K值范围**: 0-100
- **D值范围**: 0-100
- **J值范围**: 可超过100或低于0
- **超卖区**: K/D/J 三线数值 **< 20** → 关注伺机买入
- **超买区**: K/D/J 三线数值 **> 80** → 关注伺机卖出
- **徘徊区**: 20-80之间 → 观望
- **金叉**: K线上穿D线，同时J线上穿K、D线
- **超卖区金叉**: K<10, D<20, J<0 → 股价反弹可能性高
- **死叉**: K线下穿D线，同时J线下穿K、D线
- **超买区死叉**: K>90, D>80, J>100 → 短期下跌概率高
- **高位钝化**: K/D在80以上，J>100，股价仍在上涨
- **低位钝化**: K/D在20以下，J<0

**MACD+KDJ双金叉选股**:
- MACD出现金叉（绿柱消失是红柱出现的拐点）
- KDJ出现金叉且处于较低值
- 可在KDJ金叉后1-2日买入
- 准确率高达90%

**MACD黄白线零轴线上方**:
- KDJ金叉出现时是买入机会
- 只做强势区域的KDJ金叉

### 3. BOLL 布林线
- **标准参数**: 20日线，2倍标准差
- **书中推荐参数**: **26日线**（比20日线更灵敏、更高效）
- **上轨**: 压力位，短线卖出点
- **中轨**: 多空分界线，上轨之下为可操作趋势
- **下轨**: 支撑位，短线买入点
- **超买**: 股价冲出上轨线将有回调
- **超卖**: 股价跌出下轨线将有反抽

**BOLL+KDJ+MA5+MACD**:
1. 股价连续下跌，KDJ金叉当天或第二天，股价突然从下轨附近站上5日均线 → 最佳买入时机
2. 股价从下方靠近中轨线，一举突破中轨线，站上5日线，MACD金叉 → 买入机会
3. 股价在上升轨道运行，随后跌破中轨线和5日线，KDJ死叉 → 卖出信号

**BBIBOLL (多空布林线)**:
- 参数: (1, 6) 或 (11, 6)
- 法则一：缩口变张口，中轨线上方有阳线 → 行情涨
- 法则二：行情上涨时，K线实体突破上轨线 → 大概率回调；行情下跌时，K线实体跌破下轨线 → 大概率反弹

### 4. PSY 心理线
- **标准参数**: 12日
- **正常范围**: 25-75（12天内上涨天数3-9天为正常）
- **超买**: PSY ≥ 75（12天内上涨天数≥9天）→ 警惕下跌风险
- **超卖**: PSY ≤ 25（12天内上涨天数≤3天）→ 关注反弹
- **PSY超卖 + 跌破5日线**: 可逢低建仓
- **PSY超卖选股**: PSY数值小于25，盈利概率90%
- **震荡市中PSY大幅下跌**: 久盘必跌，应果断出局

### 5. DMI
- **标准参数**: (14, 6)
- **PDI (<5) 超跌**: PDI数值小于5说明该股处于超跌状态
- **PDI在MDI上方**: 强势市场
- **MDI在PDI上方**: 空头市场
- **ADX趋势判断**: 一旦突破盘局并走向极端，ADX向上运行，发出转向警告
- **四条线都在50以下横盘**: 盘整，观望

**DMI+PSY 捕捉反弹**:
- PDI < 5（超跌）
- PSY ≤ 25（市场悲观）
- 观望等待第一个阳线买入
- ADX转头向下 → 反弹结束，直接出货

### 6. 乖离率 BIAS
- **作者推荐参数**: 三个参数都改为5（只用5日均线乖离率）
- **大盘股**: 乖离率超过 **2%** → 超跌反弹/超涨回档
- **小盘股**: 乖离率超过 **4%** → 超跌反弹/超涨回档
- **A股高波动期（2015-2016）**: 标准可能是 **5%**
- **正乖离率大**: 卖出时机
- **负乖离率大**: 买入时机

### 7. SAR 止损
- **参数**: af=0.02, afmax=0.2
- **SAR翻红**: 买入
- **SAR翻绿**: 卖出
- **中线**: 周线级别使用，沪深300，红色入场绿色空仓
- **短线角度判断**: 曲线向下角度过大 → 跌势迅猛；曲线向下角度逐渐变小 → 可以逢低买入

### 8. ROE 净资产收益率
- **10%–15%**: 一般
- **15%–20%**: 良好
- **20%–30%**: 优秀（巴菲特标准 > 20%）
- 超过30%：极优秀（如贵州茅台）

### 9. 市盈率 PE
- 市盈率 = 股价 ÷ 每股收益
- 三种市盈率: 静态（过去）、滚动TTM（现在）、动态（未来）

### 10. 筹码分布
- **获利不抛的筹码是主力筹码**（获利30%以下难见主力出货）
- **解套不卖的筹码是主力筹码**
- **横盘洗不掉的筹码是主力筹码**
- **上峰不移，下跌不止**
- **下峰锁定，行情未止**
- **低位单峰密集**: 突破须有成交量配合

### 11. TOWER 宝塔线
- 翻红 → 买入
- 翻绿 → 卖出
- **三平顶翻绿**: 连续三个或以上同一水平位置的绿柱体 → 见顶，清仓
- **三平底翻红**: 连续三个或以上向上的红柱体 → 超跌反弹，可买入
- 极端行情：平顶或平底大多只会出现两个

## 二、均线系统

### 均线止损法（5日均线）
- K线站上5日均线 → 买入
- K线跌破5日均线 → 卖出
- 止损位随盈利增长逐步提高
- 尽量不要买入远离5日均线的股票
- 若股票频繁接触5日均线，应修改参数找更合适的均线（如9日均线）

### 二线法（5日+10日）
- 5日均线下穿10日均线 → 清仓
- 5日均线上穿10日均线 → 短线操作
- 大盘下跌途中，5日不上穿10日绝不动

### 长短均线法（5日+10日+60日）
- 5日、10日均线金叉向上，60日均线方向也向上 → 助涨
- 5日、10日均线死叉向下，60日均线方向也向下 → 助跌
- 回档时5日、10日与60日之间要有空隙（60日线起支撑作用）
- 每一个金叉都比前一个金叉位置高 → 保持上涨趋势
- 低于前一金叉 → 考虑下车
- 三线顺上不做空，三线顺下往往是暴跌的开始

### 三分法（7日+13日+20日）
**止损系统**:
- 跌破7日均线 → 卖出1/3仓位
- 跌破13日均线 → 卖出1/3仓位
- 跌破20日均线 → 全部清仓
- 暴涨破7日线直接清仓

**买入系统**:
- 站上7日线 → 买入1/3仓位
- 站上13日线 → 买入1/3仓位
- 站上20日线 → 满仓

**总仓位控制**: 可调整，如总仓位6成，则每站上一条线买入2成
- 准确率约85%
- 最大克星：横盘震荡（三线缠绵在一起时观望）

### 60日生命线
- K线站上60日均线 → 积极做多
- K线跌破60日均线 → 空头市场，空仓等待
- 应用在大盘指数上效果极佳

### 357均线法（3日+5日+7日+9日）
- 3日/5日/7日均线顺势排列 → 上升趋势
- 短线以7日均线为支撑
- 开盘在3日和7日均线之间，回调至7日不破 → 震荡后向上
- 收盘在3日均线之上 → 第二天均有溢价
- 3日均线掉头击破7日均线 → 落袋为安
- 站上5日均线 → 建仓
- 强势股上穿三线 → 建仓

## 三、成交量

### 成交量心法口诀
1. 新量新价有新高 → 放量配合新高，继续看涨
2. 缩量回调不必逃 → 缩量回调，继续持股
3. 放量滞涨要当心 → 量创新高股价不涨，注意风险
4. 无量上涨必须跑 → 缩量上涨，高位特别注意

### 顶量与底量
- 底量 > 顶量 → 容易通过顶量压力带
- 底量远大于顶量 → 主力不把前头部看在眼里

### 高量柱战法
- 高量不破，后市必火
- 在高量柱对应K线最低点画线，后面不破则持有
- 阴线跌破画线位置 → 平仓
- 阳线低开画线位置 → 可持仓或半仓

### 反弹条件
- 反弹幅度 > 昨日跌幅的 **50%**
- 今日成交量 > 昨日成交量 **20%**
- 符合条件可建仓20%，确认后加仓

### 妖股成交量规律
- 小板块：连续涨停4-5天基本到头
- 大板块：三板放量分歧→四板缩量加速→六板抛压
- 分歧→一致→分歧→一致

## 四、盘口分析

### 量比
- 量比 > 1 → 当日交易活跃
- 量比 < 1 → 成交量萎缩
- **量比选股**: 量比 > 2.5，换手率 < 5%
- **尾盘选股条件**: 量比 > 1.5，换手率 > 3%，流通股本 < 20亿，振幅 < 5%，20天内有涨停历史

### 换手率
- 换手率 = 成交量 / 流通总股数 × 100%
- 1%–2.5%: 大多股票范围
- 3%以下: 70%的股票
- 3%: 分界线
- 换手率+量价背离 → 顶部信号

### 分时量
- 涨缩量+跌放量 → 后市看跌
- 涨放量+跌缩量 → 后市看涨
- 反弹有量 → 更高价格；反弹无量 → 后市会掉下来

### 内外盘
- 外盘大 → 主动性买入多
- 内盘大 → 主动性卖出多
- 外大价跌 → 主力出逃
- 内大价涨 → 主力吸筹

### 集合竞价
- 9:15-9:20: 可下单可撤单，不可靠
- 9:20-9:25: 可下单不可撤单，真实
- 9:25: 撮合成开盘价
- 要买挂涨停价，要卖挂跌停价

## 五、实战战法

### 区间交易法
- 将波动区间分成若干等份
- 跌0.5元（或0.2元）买入，涨0.5元（或0.2元）卖出
- 适合：套牢型、横盘震荡型、震荡上升型
- 不适合：单边下跌、单边上升
- 7-8元股票新手可拿0.2-0.3元为区间
- 用ATR指标选波动大的股票

### 地摊法（仓位管理）
- 资金分成5-10等份
- 每份止损5%
- 安全线设定（时间止损+价格止损）
- 止损线提高到入场价位
- 盈利目标20%（止盈）
- 每份资金逐一盘活，最终满仓

### 麻雀战术
- 目标：每次赚 **2.5%** 净利润
- 模式一：买入价+2.5%净利润价预先填单卖出
- 模式二：每多涨1个点卖出10%，直到卖完
- 模式三：一旦不能创新高，在每个高点分批卖出，回落至净利润2.5%时彻底清仓
- 跌破买入价立即止损

### 龙回头战法
- 条件1：第一波大幅拉升（涨停板）
- 条件2：下跌过程中缩量
- 条件3：股价回落至重要支撑位止跌企稳
- 均线支撑 / 多空布林线支撑

### 打板
- 扫板：离涨停还有几档就挂涨停价扫货
- 打板：最后一档即将被吃完时买入
- 排板：大单封死后排队
- 回封板：炸板后横盘震荡，回封时买入
- 条件：高开1%-2%，成交量昨日2倍以上，量比>2，换手率>3%

### T+0 做T
- 巨量下跌 → 买入
- 巨量上涨 → 卖出
- 二次买入要有一定差距（约1个点）
- 被套牢股票T+0有利润就出一部分
- 选择上涨趋势中有一定调整幅度的股票

### 抄底法（60日+120日均线）
- MA60和MA120组成区间带
- K线站在带上 → 上涨行情
- 跌破区间带 → 下跌行情
- 红色做多，绿色做空

### 压力支撑（画线法）
- 斜线：趋势支撑线，连接止跌点
- 横线：多空转换线
- 多次下跌不破的才是支撑
- 多次上涨不破的才是压力
- 触碰3次以上有效性最强
- 连接K线实柱比影线更有效

## 六、选股技巧

### 尾盘选股法（14:30后）
1. 大盘15分钟K线处于上升趋势
2. 选股条件：振幅<5%，流通股本<20亿，换手率>3%，量比>1.5，20天内有涨停
3. 形态优选：平台突破、主升浪上攻、回踩支撑
4. 分时图白线回踩均线不破，持续有大单买入

### 早盘选股法
1. 总股本<3亿（小盘股）
2. 涨幅>3%
3. 换手率>2%
4. 量比>1.5倍
5. DMI中ADX值>30（或MACD中DIF值>30）
6. 外盘>内盘，差距越大越好
7. 去掉已涨停的

### 热门选股法
**换手率法**:
1. 打开换手率排序，关注排行榜
2. 寻找细分行业出现最多的板块
3. 加入自选股，符合交易系统的留下

**涨幅榜法**:
1. 给涨幅榜排序
2. 寻找热门板块和股票
3. 符合交易系统的加入自选

### 题材逻辑选股
- 大题材：以月为单位，龙头翻倍涨幅
- 中题材：以周为单位，龙头涨幅50%
- 小题材：几天结束，涨幅20-30%
- 大题材类别：政策类、科技稀缺类、天生牛股基因类
- 9大判断标准：市场容量、业绩支撑、博弈难度、标的物市值、政策力度、持续时间、事件性质、方案详尽度、是否首次炒作

### 价值选股十条
1. 有竞争力的公司
2. 产品单一，一个产品打天下
3. 低投入、高产出的公司
4. 利润总额高（年利润5亿以上，增长率>10%）
5. 净资产收益率高（>20%，<10%淘汰）
6. 稳定高毛利率的公司
7. 应收款少、预收款多的公司
8. 行业龙头的公司
9. 每股收益高、借款金额少
10. 婴儿股本、巨人品牌、行业老大
