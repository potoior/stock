# A股量化分析

输入股票代码,获取实时行情 + 56个策略信号 + 综合买卖建议;支持策略管理、回测、选股。

## 快速开始

```bash
# 分析单只股票
uv run {baseDir}/scripts/cli.py analyze 600789

# 分析多只股票
uv run {baseDir}/scripts/cli.py analyze 600789 000001 600519
```

## 触发方式

以下场景会自动激活此 skill:

- `/a-stock 600789`、`分析一下600789`、`600789能买吗`
- "关闭MACD策略"、"把KDJ策略打开"、"调整BOLL参数"
- "回测一下MACD策略"、"MACD策略历史表现怎么样"
- "用KDJ策略选股"、"哪些股票今天触发了金叉信号"
- "龙回头是什么策略"(查策略大全)

## 子命令

| 子命令 | 用法 | 说明 |
|--------|------|------|
| analyze | `analyze <codes...>` | 多股分析,56策略信号 + 综合建议 |
| list | `list` | 策略列表(开关状态 + 当前参数) |
| toggle | `toggle <id> <on\|off>` | 开关策略 |
| params | `params <id> <k=v ...>` | 调整策略参数 |
| backtest | `backtest <id> <code> [--days N]` | 单策略个股回测(胜率/超额收益) |
| scan | `scan <id> [--codes c1,c2] [--top N]` | 策略选股:指定股票池或本地缓存全部 |
| library | `library [keyword]` | 查策略大全(4来源73策略) |

| 分组 | 策略 |

| 投资法则(4) | 顺势而为、金字塔买卖、暴利收手、计划交易 |
| 量能/实战(5) | 高量柱、看妖股、龙回头、压力支撑、区间交易 |
| 实战战法(2) | 打板策略、复盘法 |
| 抄底/逃顶(4) | 均线识底、时间识底、周线见顶、月线见顶 |
| 跟庄(5) | 庄家试盘、庄家建仓、庄家拉高、庄家出货、庄家洗盘 |
| 涨停细分(3) | 涨停类型、涨停封不牢、拉高型涨停 |
| 基本面(4) | 市盈率选股、ROE+PE选股、股东人数选股、政策选股 |
| 经典形态(6) | K线形态、MACD顶背离、MACD底背离、RSI顶背离、RSI底背离、缺口识别 |

观察型策略(庄家试盘/庄家洗盘/拉高型涨停)只输出观察信息,不产生买卖信号,不可用于选股扫描。
需联网外部数据的策略(股东人数/政策选股)不可用于扫描,只能分析个股。

## 综合建议判定

方向票须达到启用策略数的 40% 且压制对方;未达阈值时,需 3 票以上且 2 倍压倒性优势才给方向,否则多空对峙 → 观望。

## 状态持久化

- 开关/参数写入 `~/.a-stock/config.json`,analyze 自动生效
- K线缓存在 `~/.a-stock/stock_cache.db`,scan(不带 --codes)扫描缓存中的全部股票

## 数据来源

| 数据 | 来源 | 说明 |
|------|------|------|
| 实时行情 | 新浪财经 hq.sinajs.cn | 延迟约3秒 |
| 历史K线 | 腾讯前复权 fqkline (qfq) | 与同花顺/通达信数值一致 |

MACD/BBIBOLL/DMI/BIAS 等指标按通达信标准公式计算;涨停判定用真实涨停价(主板10%/创业板科创板20%/北交所30%,ST主板5%,四舍五入到分)。

## 注意事项

- 数据延迟约3秒,不适合追涨停板等毫秒级交易
- backtest 为简化事件回测(信号次日开盘价成交),仅供策略横向对比
- 所有建议仅供参考,不构成投资建议
- 股市有风险,投资需谨慎
