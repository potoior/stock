# A股量化分析

输入股票代码，立即获取实时行情 + 17个策略信号 + 买卖建议 + 详细理由。

## 快速开始

```bash
# 分析单只股票
uv run {baseDir}/scripts/analyze.py 600789

# 分析多只股票
uv run {baseDir}/scripts/analyze.py 600789 000001 600519
```

## 触发方式

以下场景会自动激活此 skill：

- `/a-stock 600789`
- "分析一下600789"
- "600789能买吗"
- "帮我看看鲁抗医药"
- "查一下股票行情"
- "这只股票怎么样"

## 17个策略信号

| # | 策略 | 买入条件 | 卖出条件 |
|---|------|---------|---------|
| 1 | MACD金叉死叉 | 零上金叉/多次零下金叉 | 零下死叉 |
| 2 | KDJ超买超卖 | K<10,D<20 超卖区金叉 | K>90,D>80 超买区死叉 |
| 3 | 5日均线止损 | 价格站上MA5 | 价格跌破MA5 |
| 4 | BOLL布林线(26日) | 触及下轨/中轨上方 | 触及上轨/中轨下方 |
| 5 | DMI趋势 | PDI>MDI 多方主导 | MDI>PDI 空方主导 |
| 6 | PSY心理线 | PSY≤25 超卖 | PSY≥75 超买 |
| 7 | BIAS乖离率(±3%) | BIAS≤-3% 超跌 | BIAS≥+3% 超涨 |
| 8 | SAR止损 | 价格>SAR 翻红 | 价格<SAR 翻绿 |
| 9 | 三指标共振 | MACD金叉+KDJ金叉+BOLL中轨+MA5 | 任一指标走坏 |
| 10 | 均线组合(5/10/60) | 5>10>60 多头排列 | 跌破5日或10日 |
| 11 | 量价背离 | 量价配合 | 价创新高量萎缩 |
| 12 | DMI+PSY超跌 | PDI<5 + PSY≤25 | ADX转头 |
| 13 | 三分法(7/13/20) | 站上7/13/20日线 | 跌破7日线 |
| 14 | 麻雀战术 | - | 2.5%止盈 |
| 15 | 反弹量化 | 涨幅>昨日跌幅50%+量增20% | - |
| 16 | 二线法(5/10) | MA5>MA10 | MA5<MA10 |
| 17 | 60日生命线 | 价格>MA60 做多 | 价格<MA60 空仓 |

## 数据来源

| 数据 | 来源 | 延迟 |
|------|------|------|
| 实时行情 | 新浪财经 hq.sinajs.cn | ~3秒 |
| 历史K线 | 新浪财经 getKLineData | 日线 |

## 注意事项

- 数据延迟约3秒，不适合追涨停板等毫秒级交易
- 技术指标基于日K线计算，适合中线趋势判断
- 所有建议仅供参考，不构成投资建议
- 股市有风险，投资需谨慎
