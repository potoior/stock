# A股量化交易系统

基于《半小时漫画股票实战法》知识库搭建的 A股量化回测与信号系统。

## 目录结构

```
stock/
├── quant/                    # 量化系统
│   ├── data_fetcher.py       # 数据获取（新浪财经 + SQLite缓存）
│   ├── strategies.py         # 策略实现（MACD/KDJ/均线）
│   ├── backtest.py           # 回测引擎
│   ├── gen_report.py         # 报告生成
│   └── 回测报告.md            # 最新回测结果
├── output/
│   ├── 半小时漫画股票实战法_知识库.md   # 策略知识库（阅读版）
│   └── strategy_knowledge.json        # 策略知识库（结构化）
```

## 数据源

| 数据 | 接口 | 说明 |
|------|------|------|
| 实时行情 | 新浪 `hq.sinajs.cn` | 延迟约3秒 |
| 历史K线 | 新浪 `getKLineData` | 最多1024条日K |
| 全市场扫描 | 待接入 | 需批量接口 |

> 注意：东方财富 API 在部分网络环境被限流，故使用新浪财经作为主数据源。

## 已实现策略

1. **MACD金叉死叉** - 快慢线金叉买入、死叉卖出
2. **KDJ超买超卖** - 超卖区金叉买入、超买区死叉卖出
3. **5日均线止损法** - 站上5日线买入、跌破卖出

## 使用方法

```bash
# 进入环境
cd quant
.venv\Scripts\activate

# 运行回测
python backtest.py

# 生成报告
python gen_report.py
```

## 回测参数

- 回测区间：2022-06-01 ~ 2024-08-01
- 初始资金：100,000 元
- 佣金：0.025%
- 股票池：10只代表股票

## 知识库

策略知识库基于《半小时漫画股票实战法》全书内容提取，包含：

- 11 个技术指标（MACD/KDJ/BOLL/PSY/DMI/BIAS/SAR/ROE/市盈率/筹码分布/宝塔线）
- 6 个均线系统策略
- 5 个成交量策略
- 6 个盘口分析技巧
- 9 个实战战法
- 4 个选股技巧

见 `output/strategy_knowledge.json` 和 `output/半小时漫画股票实战法_知识库.md`
