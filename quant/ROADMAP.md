## 一、数据层拓展

### 1.1 全市场股票池
当前：手动指定股票代码

目标：自动获取全市场 A 股列表

```python
# 获取全市场股票列表（AKShare 或 Sina）
ak.stock_zh_a_spot_em()  # 全市场实时行情（上海+深圳+北交所）
```

- 约 5000 只 A 股
- 按行业/板块分类
- 按市值/成交量过滤

### 1.2 多数据源切换
| 数据源 | 数据类型 | 延迟 | 限制 |
|--------|---------|------|------|
| 新浪财经 | 日K线、实时行情 | 实时 | 最多1024条日K |
| AKShare(东方财富) | 日K/周K/月K/分钟K、财务数据 | 实时 | 需代理/网络稳定 |
| Tushare Pro | 全量数据 | 实时 | 需注册付费 |

建议：新浪做实时、AKShare 做历史补充、Tushare 做财务数据

### 1.3 数据补全
- 当前只有日K线，缺少周K、月K、分钟K线
- 缺少财务数据（ROE、市盈率、毛利率等）
- 缺少板块/行业分类数据
- 缺少龙虎榜/北向资金等辅助数据

| 战法 | 量化实现难度 | 说明 |
|------|------------|------|

| 高量柱战法 | 中 | 放量突破关键位 |
| 麻雀战术 | 中 | 短期高频止盈 |
| 打板策略 | 高 | 涨停板追击，需要 Level-2 数据 |

### 2.2 策略改进方向

#### 当前策略的问题
- **MACD 金叉死叉**：滞后性明显，在震荡市中频繁假信号
- **KDJ 超买超卖**：单独使用胜率低，需结合趋势过滤
- **5日均线止损法**：在震荡市中频繁止损

#### 改进方向
1. **多周期过滤**：日线信号 + 周线趋势确认
2. **大盘环境过滤**：大盘上涨时只做多，下跌时空仓
3. **波动率过滤**：低波动时减少交易，高波动时谨慎
4. **止损优化**：ATR 动态止损替代固定比例止损

## 三、系统架构升级

### 3.1 当前架构
```
realtime.py → 新浪实时行情 → 手动计算信号 → 终端输出
```

### 3.2 目标架构
```
┌────────────────────────────────────────────────┐
│                 调度层                          │
│  定时任务(cron) → 每日收盘后自动扫描全市场       │
└────────────────────┬───────────────────────────┘
                     ↓
┌────────────────────────────────────────────────┐
│                 数据层                          │
│  新浪(实时) + AKShare(历史) + Tushare(财务)     │
│  → SQLite 统一缓存                              │
└────────────────────┬───────────────────────────┘
                     ↓
┌────────────────────────────────────────────────┐
│                 策略层                          │
│  知识库 41 个策略 → 多策略并行计算               │
│  → 信号综合评分                                  │
└────────────────────┬───────────────────────────┘
                     ↓
┌────────────────────────────────────────────────┐
│                 输出层                          │
│  ├─ 终端输出（当前）                             │
│  ├─ Web 看板（Flask/Gradio）                    │
│  ├─ 飞书/微信推送                               │
│  └─ 信号文件（供自动交易使用）                    │
└────────────────────────────────────────────────┘
```

### 3.3 技术栈升级建议
| 组件 | 当前 | 推荐升级 |
|------|------|---------|
| 数据获取 | 新浪直接 HTTP | 统一 DataFetcher 接口 |
| 策略计算 | 实时.py 手动计算 | Backtrader 策略复用 |
| 定时任务 | 无 | Windows 任务计划 / cron |
| 信号推送 | 终端输出 | 飞书 Webhook / 邮件 |
| Web 看板 | 无 | Gradio（一行代码快速搭建） |

## 四、实时交易

### 4.1 信号推送（推荐先做）
- 每日收盘后自动扫描全市场
- 按策略筛选出符合条件的股票
- 推送到飞书/微信/邮件

### 4.2 模拟交易
- 在 Backtrader 中模拟实时交易
- 记录每笔交易日志
- 统计胜率、盈亏比

### 4.3 自动交易（谨慎）
- 需要对接券商接口
- 推荐：`easytrader`（支持同花顺/华泰/东方财富等）
- 风险控制：
  - 单笔交易不超过总资金 2%
  - 单日交易不超过 5 次
  - 设置硬止损线

## 六、需要你注意的问题

### 6.1 技术问题
- 当前网络需要代理（127.0.0.1:7897）
- AKShare 的东方财富数据源被限流，需走代理
- 新浪数据最多 1024 条，约 4 年，更长期需其他数据源

### 6.2 策略风险
- 回测结果不代表未来表现
- 简单策略在震荡市容易亏损
- 实盘前务必经过充分模拟验证

### 6.3 法律合规
- 个人量化交易在中国是合法的
- 自动下单需确保符合券商规定
- 不建议使用爬虫高频访问券商接口
