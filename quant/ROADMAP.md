### 2.2 策略改进方向

#### 当前策略的问题
- **MACD 金叉死叉**：滞后性明显，在震荡市中频繁假信号
- **KDJ 超买超卖**：单独使用胜率低，需结合趋势过滤
- **5日均线止损法**：在震荡市中频繁止损

#### 改进方向
1. **多周期过滤**：日线信号 + 周线趋势确认
2. **大盘环境过滤**：大盘上涨时只做多，下跌时空仓
3. **波动率过滤**：低波动时减少交易，高波动时谨慎
4. **止损优化**：ATR 动态止损替代固定比例止损

## 三、系统架构升级

### 3.1 当前架构
```
realtime.py → 新浪实时行情 → 手动计算信号 → 终端输出
```

### 3.2 目标架构
```
┌────────────────────────────────────────────────┐
│                 调度层                          │
│  定时任务(cron) → 每日收盘后自动扫描全市场       │
└────────────────────┬───────────────────────────┘
                     ↓
┌────────────────────────────────────────────────┐
│                 数据层                          │
│  新浪(实时) + AKShare(历史) + Tushare(财务)     │
│  → SQLite 统一缓存                              │
└────────────────────┬───────────────────────────┘
                     ↓
┌────────────────────────────────────────────────┐
│                 策略层                          │
│  知识库 41 个策略 → 多策略并行计算               │
│  → 信号综合评分                                  │
└────────────────────┬───────────────────────────┘
                     ↓
┌────────────────────────────────────────────────┐
│                 输出层                          │
│  ├─ 终端输出（当前）                             │
│  ├─ Web 看板（Flask/Gradio）                    │
│  ├─ 飞书/微信推送                               │
│  └─ 信号文件（供自动交易使用）                    │
└────────────────────────────────────────────────┘
```

### 3.3 技术栈升级建议
| 组件 | 当前 | 推荐升级 |

## 七、交易 Agent 架构设计

### 7.1 什么是交易 Agent？

交易 Agent 是一个能**自主感知市场 → 分析决策 → 执行交易 → 自我反馈**的闭环系统。

```
         ┌─────────────────────────────────────────┐
         │             交易 Agent                   │
         │                                          │
 感知层   │  ├─ 实时行情监控                         │
         │  ├─ 全市场扫描                           │
         │  └─ 财务/消息数据                        │
         │                                          │
 决策层   │  ├─ 多策略并行计算                       │
         │  ├─ 信号综合评分                         │
         │  └─ 风险控制（仓位/止损）                 │
         │                                          │
 行动层   │  ├─ 模拟盘（记录交易）                   │
         │  ├─ 实盘下单（easytrader）               │
         │  └─ 结果记录                             │
         │                                          │
 反馈层   │  ├─ 交易日志分析                         │
         │  ├─ 策略胜率统计                         │
         │  └─ 参数自动优化                         │
         └─────────────────────────────────────────┘
```

### 7.2 当前状态 vs 目标

| 能力 | 当前 | Agent 目标 |
|------|------|-----------|
| 感知 | 手动输入股票代码 | 自动全市场扫描 |
| 决策 | 终端输出信号 | 带仓位的完整交易指令 |
| 行动 | 无 | 模拟盘 + 可选实盘 |
| 反馈 | 无 | 自动记录分析每笔交易 |
| 运行 | 手动执行 | 定时循环自主运行 |

### 7.3 Agent 核心模块设计

#### 模块 1：`agent.py` —— 主循环
```
while True:
    1. 拉取全市场实时行情
    2. 对持仓股计算策略信号
    3. 检查持仓是否需要止损/止盈
    4. 检查是否有新买入机会
    5. 执行交易（模拟/实盘）
    6. 记录日志
    7. 等待下一个周期（如 5 分钟）
```

```python
class TradingAgent:
    def __init__(self, mode="simulation"):
        self.mode = mode  # simulation / real
        self.portfolio = {}  # code -> {qty, cost, buy_date}
        self.trades = []     # 交易历史
        self.strategies = [...]  # 策略列表

    def run(self, interval=300):
        """每 interval 秒执行一个周期"""
        while True:
            self.cycle()
            time.sleep(interval)

    def cycle(self):
        """一个完整的交易周期"""
        data = self.fetch_market()
        signals = self.analyze(data)
        orders = self.decide(signals)
        self.execute(orders)
        self.record()
        self.report()
```
